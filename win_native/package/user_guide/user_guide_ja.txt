MirrorDock ユーザーガイド
=========================

MirrorDock は、iPhone や iPad の映像と音声を
Wi-Fi または USB ケーブル経由で Windows PC
で再生するプログラムです。PC のマウスと
キーボードで iPhone を操作することも
できます（セクション 5 を参照）。ファイルは
mirror_dock.exe ひとつだけで、ほかに
インストールするものはありません。
（バージョン 1.6 までは「UxPlay for Windows」
という名前でした。以前のバージョンから
移行する場合は、最後のセクションを
ご覧ください。）

動作環境: Windows 10 または 11（x64）。
プログラムは、実行している PC に合わせて
自動的に調整されます。ディスプレイを
駆動している GPU を使い（内蔵 GPU でも
グラフィックボードでも、Intel、AMD、NVIDIA
のいずれでも構いません。GPU が映像を
デコードできない場合は、ソフトウェア
デコードに切り替わります）、ディスプレイの
解像度とリフレッシュレートを読み取り
（ディスプレイの接続や取り外しにも
追従します）、オーディオデバイスが対応する
最小の遅延で動作します。別の PC に移しても、
設定をやり直す必要はありません。


1. 起動と終了
-------------
・mirror_dock.exe をダブルクリックします。
  コンソールウィンドウは開きません。
  通知領域（時計の横）にアイコンが現れ、
  初回は「準備完了」の通知が表示されます。
  iPhone が接続するまでウィンドウはなく、
  すべての機能はこのアイコンのメニューに
  あります（左クリックでも右クリックでも
  開きます）。
・約 0.5 秒以内に、iPhone の
  「画面ミラーリング」の一覧に PC が
  表示されます。
・「Windows セキュリティの重要な警告」が
  表示されたら、「許可」を選びます
  （家庭内のネットワークは
  「プライベート ネットワーク」です）。
  キャンセルした場合は、iPhone から PC が
  見つかりません。「Windows セキュリティ >
  ファイアウォールとネットワーク保護 >
  ファイアウォールによるアプリケーションの
  許可」を開き、mirror_dock.exe にチェックを
  入れてください。
・同じ名前で実行できるのは 1 つだけです。
  もう一度起動しても、実行中のプログラムが
  「すでに実行中です」という通知を
  表示するだけです。
・映像ウィンドウを閉じても、終わるのは
  そのミラーリングだけです。プログラムは
  バックグラウンドで次の接続を待ち続けます。
・終了するには、通知領域のアイコンの
  メニューで「終了」を選びます（iPhone にも
  伝えられ、iPhone の一覧から PC が
  消えます）。
・Windows と一緒に起動するには、メニューで
  「Windows 起動時に実行」を選びます
  （もう一度選ぶとオフになります。設定は
  現在のユーザーアカウントだけに適用され、
  管理者権限は必要ありません）。
・プログラムを起動できない場合（ポートが
  使用中、オプションの書き間違いなど）は、
  原因とログファイルの場所を示す
  ダイアログが表示されます。


2. Wi-Fi でミラーリング
-----------------------
iPhone と PC を同じ Wi-Fi ネットワークに
接続し、iPhone で「コントロールセンター >
画面ミラーリング」を開いて
「MirrorDock@コンピューター名」を選びます。
映像ウィンドウが現れ、最前面に表示されます。
iPhone をロックすると、iOS は映像を
一時停止しますが、音声はそのまま流れ
続けます。ロックを解除すると映像も
再開します（これは正常な動作です）。
この方法ではドライバーは不要で、
モバイルデータ通信も使いません。


3. USB ケーブルでミラーリング
-----------------------------
AirPlay は、iPhone が USB ケーブル上に
用意するネットワーク接続を通じて動作します。
この接続があるあいだ、MirrorDock はそれを
優先して使い、ケーブルを抜くと Wi-Fi に
戻ります。プログラムの実行中は、ケーブルの
抜き差しに約 2 秒以内で追従します
（進行中のミラーリングは中断されず、
それが終わった時点で切り替わります）。

  1. Apple の USB ドライバーをインストール
     します（初回のみ）。同梱の
     install_apple_usb_support.cmd を
     実行するか（これは winget で
     Apple Mobile Device Support を
     インストールします）、Microsoft Store
     から「Appleデバイス」をインストール
     します。
  2. iPhone で「設定 > インターネット共有」を
     開き、「ほかの人の接続を許可」をオンに
     してから、USB ケーブルを接続します。
     Windows に
     「Apple Mobile Device Ethernet」という
     ネットワークアダプター（172.20.10.x）が
     追加されます。iPhone を接続しても
     インターネット共有がオフのままの場合は、
     約 8 秒後に通知でお知らせします
     （1 回の実行につき 1 度だけ）。
  3. iPhone で「コントロールセンター >
     画面ミラーリング > MirrorDock」を
     選びます。
     コントロールバーと通知領域のアイコン
     には、実際に使われている経路に応じて
     「USB」または「Wi-Fi」と表示されます。
  メニューの 2 行目には、USB 接続の状態が
  表示されます: 未接続 /
  インターネット共有をオンにしてください /
  準備完了 / ネットワークアダプターが無効 /
  充電のみ。

USB と Wi-Fi の切り替え（ケーブルは充電の
ためにつないだままで構いません）:
  コントロールバーまたはメニューで、次の
  どちらかを選びます。
    ・「USB 優先」: iPhone がつながっていて
      インターネット共有がオンのあいだは、
      USB を使います（既定）。
    ・「Wi-Fi のみ」: ミラーリングには常に
      Wi-Fi を使い、ケーブルは充電だけを
      行います。
  選んだ内容は記憶されます。ミラーリング中に
  切り替えると、そのミラーリングは終了
  します。iPhone の「画面ミラーリング」で、
  もう一度 PC を選んでください。

  「Wi-Fi のみ」は、USB を確実に締め出します。
  プログラムは USB 側の接続には応答せず、
  それでも USB 経由で届いた接続は拒否します。
  そのため、切り替えのためにデバイスや
  ネットワークアダプターを無効にする必要は
  ありません（無効にはしないでください。
  USB でのミラーリングができなくなり、
  ケーブルによっては充電も止まります）。
  以前に「Apple Mobile Device Ethernet」を
  無効にしていた場合は、「USB 優先」を
  選んだときにプログラムがお知らせします。
  通知（または
  「USB ネットワークアダプターを有効にする…」）
  をクリックし、管理者権限の確認画面で
  「はい」を選んでください。

モバイルデータ通信について:
・ミラーリングそのものは、iPhone から PC へ
  ケーブルで送るローカルの転送です。
  通信事業者の回線は通らず、
  モバイルデータ通信も使いません。
・ただし、インターネット共有がオンのあいだ、
  Windows が PC 自身のインターネット通信を
  iPhone のモバイルデータ通信に流すことが
  あります（自宅の Wi-Fi に IPv6 がなく、
  iPhone が通信事業者の IPv6 を提供している
  場合によく起こります）。
・プログラムがこの状態に気づくと、通知を
  表示します。
  通知（または「データ通信量を節約…」）を
  クリックし、管理者権限の確認画面で
  「はい」を選んでください。この操作が
  必要なのは 1 回だけです。それ以降、
  ケーブルを流れるのはミラーリングだけに
  なり、PC は自分のネットワークを使い
  続けます。Wi-Fi が切れても、PC が iPhone の
  データ通信に切り替わることはありません。
・iPhone の「モバイルデータ通信」は
  オンのままにしてください。オフにすると、
  ケーブル上のローカル接続も含めて
  インターネット共有がなくなり、USB での
  ミラーリングが止まります。
・あとで、PC からケーブル経由で iPhone の
  インターネット接続をもう一度使いたく
  なった場合は、管理者として実行した
  コマンド プロンプトで元に戻します
  （<n> は Apple のアダプターの
  インターフェイス番号で、
  「netsh interface ipv4 show interfaces」
  で確認できます）。
    netsh interface ipv4 set interface <n> ignoredefaultroutes=disabled
    netsh interface ipv6 set interface <n> routerdiscovery=enabled ignoredefaultroutes=disabled

注: iOS 16 以降、Apple は従来の
「QuickTime」方式の有線画面キャプチャ
（インターネット共有が不要だった方式）を
無効にしました。そのため、このプログラムは
その方式を使いません。上で説明した方法が、
現在の iOS で使える有線ミラーリングです。


4. ウィンドウ、コントロールバー、全画面表示
-------------------------------------------
・ウィンドウのサイズ: iPhone が縦向きのとき、
  ウィンドウは画面の高さの約 90% に
  なります。横向きにすると画面の幅の
  約半分になり、画面いっぱいに近い大きさに
  なることはありません。ウィンドウの枠を
  ドラッグするとサイズを変えられ、映像の
  縦横比は保たれます。自分で決めたサイズと
  位置は、縦向きと横向きで別々に
  記憶されます。
・映像の上でマウスを動かすと、下端に
  コントロールバーが現れます。マウスを
  動かさずに 3 秒たつと隠れます
  （ポインターがバーの上にあるあいだは
  隠れません）。
・コントロールバーの左側: USB か Wi-Fi か、
  および映像の解像度。
  右側: 「USB 優先 | Wi-Fi のみ」、ミュート
  （このプログラムの音だけが対象で、
  iPhone の音量は変わりません）、その他
  （すべての項目があるメニュー）、
  全画面表示。
  必要なときは、黄色のボタン
  「データ通信量を節約」「USB アダプターを有効化」
  が表示されます。
・映像の上の任意の場所を右クリックしても、
  すべての項目があるメニューが開きます。
・全画面表示: 映像をダブルクリックするか、
  F、F11、Alt+Enter のいずれかを押します。
  Esc で解除します。全画面表示では、
  マウスを動かさずに 3 秒たつと、
  ポインターとコントロールバーが一緒に
  隠れます。
・黒帯のトリミング: iPhone の画面が映像より
  横長の場合（16:9 の映画を iPhone で
  全画面再生したときなど）、iPhone は
  黒い部分も含めた画面全体を
  ミラーリングします。この黒帯を
  切り落として、ウィンドウの四辺を映像に
  ぴったり合わせることができます。
    自動: C キーを押すか、メニューで
          「黒帯を自動でトリミング」を
          選びます。映像のまわりの黒帯が
          切り落とされ、ウィンドウが映像に
          合わせて縮みます。次の映画に
          切り替わっても、トリミングは
          そのまま保たれます。黒帯の部分に
          別のものが現れて表示され続けると
          （全画面再生をやめたときなど）、
          約 1 秒以内に映像全体が再び
          表示されます。暗いシーンを黒帯と
          取り違えないよう、切り落とすのは、
          両側で同じ幅があり、約 1.5 秒
          続いていて、動きのある映像を
          囲んでいる黒帯だけです。
          この選択は記憶されます。
    手動: X キーを押すか、メニューで
          「表示する範囲を選択…」を
          選びます。ポインターが十字に
          変わるので、残したい部分を
          ドラッグして枠で囲み、ボタンを
          離します。Esc またはマウスの
          右ボタンでキャンセルできます。
          手動で囲んだ枠は現在の映像に
          だけ適用され、iPhone を回転
          させたり接続し直したりすると
          解除されます。
    解除: メニューで「トリミングなし」を
          選びます（自動のときは、
          もう一度 C キーを押しても
          解除できます）。
・常に手前に表示: T キーを押すか、
  メニューで「常に手前に表示」を選びます。
  ミュート: M キーを押します。
・ミラーリング中は、PC が自動的にスリープ
  したり画面を消したりすることは
  ありません。
・画面の表示は Windows の表示言語に
  合わせて切り替わります。対応しているのは、
  英語、繁体字中国語、簡体字中国語、日本語、
  韓国語、スペイン語、ドイツ語、フランス語、
  ベトナム語、タイ語、ロシア語です。
  それ以外の言語では英語で表示されます。
  特定の言語に固定するには、-ui オプションを
  使います（セクション 9 を参照）。


5. マウスとキーボードで iPhone を操作
-------------------------------------
iPhone を USB ケーブルでつないでいれば、
映像の上で行った操作を、そのまま iPhone で
実行できます。F8 を押すか、メニューで
「マウスとキーボードで iPhone を操作」を
選んでください。オンのあいだは、ウィンドウの
タイトルに「操作中」と表示されます。
もう一度 F8 を押すと、オフに戻ります。
この選択は記憶されます。

  左ボタン    指 1 本での操作。クリックは
              タップ、押したままにすると
              長押し、ドラッグはスワイプ
  ホイール    ポインターの下にある内容を
              スクロールする（Shift を
              押しながら回すと横方向）
  中央ボタン  ホーム画面に戻る
  ダブルクリック
              これまでどおり全画面表示の
              オン / オフ（ウィンドウ自身の
              コマンド）。Alt を押しながら
              ダブルクリックすると、
              iPhone でダブルタップ
  キーボード  iPhone につないだキーボードと
              同じように入力できる。Ctrl は
              Command キーとして働き、
              Ctrl+Space で iPhone の
              入力言語が切り替わる
  Page Down、Page Up、Alt + 矢印キー
              次または前のページや動画に
              フリックで移動する（キー入力を
              受け付けないアプリ向け）
  右ボタン    これまでどおり MirrorDock の
              メニューを開く

操作がオンのあいだも、ウィンドウ自身の
コマンドが優先されます。F8、F11、
Alt+Enter、Alt+F4、全画面表示中の Esc、
そしてダブルクリックは、これまでどおり
ウィンドウに対して働きます。
ダブルクリックでは、2 回目のクリックが
届く時点で、1 回目のクリックがすでに
タップとして iPhone に送られています。
黒帯があるときは黒帯の上でダブルクリック
するか、F11 を押してください。操作がオンの
あいだ、コントロールバーは表示されません。
iPhone の画面の下端を隠してしまうためです。
メニューは、マウスの右ボタンで
開いてください。

必要なもの:
・iOS 27 以降の iPhone を USB ケーブルで
  つなぎ、iPhone でこの PC を信頼しておきます
  （確認が表示されたら、iPhone のロックを
  解除して「信頼」をタップします）。
  ケーブルを使うのは操作だけです。映像は
  これまでどおり Wi-Fi で受け取れますし、
  「Wi-Fi のみ」を選んだままでも構いません。
・デベロッパモードをオンにします。iPhone の
  「設定 > プライバシーとセキュリティ >
  デベロッパモード」にあります。
  このスイッチは、開発ツールから要求が
  あるまで表示されません。MirrorDock は、
  初めて F8 を押したときにその要求を
  行います。オンにすると iPhone が再起動し、
  もう一度確認を求められます。
・初回と、iOS をアップデートするたびに
  その最初の 1 回は、PC がインターネットに
  つながっている必要があります。MirrorDock が
  Apple の開発者向けディスクイメージ
  （Developer Disk Image）を iPhone に
  インストールするためで、これには約 1 分
  かかります。MirrorDock はこのイメージを
  ダウンロードし（約 17 MB。
  %LOCALAPPDATA%\MirrorDock\developer_disk_image
  に保存されます）、この iPhone 向けの署名を
  Apple の署名サービスに依頼します。
  このとき、Xcode と同じように、iPhone の
  チップの識別番号が Apple に伝わります。
  それ以降、操作のために外部と通信する
  ことはありません。

この方法を使う理由: AirPlay には、iPhone に
入力を送るための経路がありません。そこで
操作には、iOS の開発者向けサービスを
使います。Apple の Xcode が実機を操作する
ときに使っているものです。
デベロッパモードは、このサービスのために
Apple 自身が用意しているスイッチです。
iPhone を脱獄するものではなく、同じ場所で
オフに戻すこともできます。


6. 画質とパフォーマンスのモード
-------------------------------
メニューで 3 つのうち 1 つを選びます。
選んだモードは記憶されます。
  ・「画質優先」: iPhone にフル解像度を
    要求し、バッファリングをやや多めに
    取って、フレームを一切スキップしません。
    映画、スライド、文字に向いています。
    遅延は「バランス」よりわずかに
    大きくなります。
  ・「バランス（自動調整）」: 既定のモード
    です。ディスプレイ、GPU、ネットワークに
    合わせて、カクつきが出ない範囲で遅延を
    できるだけ小さく保ちます。GPU が映像を
    ハードウェアでデコードできない場合は、
    軽めのストリームを要求します。
  ・「パフォーマンス優先」: 軽めのストリーム
    （最大 1920x1080）を要求し、
    バッファリングを最小限にして、遅れて
    届いたフレームを最新のフレームに
    置き換えます。遅延が最も小さく、メモリと
    GPU の負荷も最も軽いモードです。
    ゲームや古めの PC に向いています。
遅延となめらかさは、すぐに切り替わります。
ストリームの解像度は接続時に iPhone が
決めるため、解像度の変更（と「画質優先」の
深めのバッファリング）が完全に反映される
のは、次回の接続からです（プログラムが
その旨をお知らせします）。


7. ログファイルとクラッシュ記録
-------------------------------
・%LOCALAPPDATA%\MirrorDock\mirror_dock.log
  （メニューの「ログファイルを開く」）。
  すべての行に時刻が記録されます。
  前回の実行時のログは
  mirror_dock.previous.log として残ります。
  1 つのファイルは最大 8 MB です。
・10 秒ごとに、映像と音声の統計が 1 行
  書き込まれます。音が出ないときや映像が
  なめらかでないときは、どこに問題が
  あるかがここから分かります。
・プログラムが異常終了した場合は、同じ
  フォルダーに mirror_dock_crash.txt
  （発生した場所）と mirror_dock_crash.dmp
  が残ります。問題を報告するときは、
  これらを添付してください。
・mirror_dock.exe をコマンド プロンプトから
  起動した場合、ログはそこに出力されます。


8. アップデートと「バージョン情報」ウィンドウ
---------------------------------------------
・メニューの「アップデートを確認…」を選ぶと、
  最新バージョンを GitHub に問い合わせ、
  その結果を「バージョン情報」ウィンドウに
  表示します。新しいバージョンがある場合は、
  「ダウンロード」でその zip をブラウザーで
  開き、「変更点」でリリースノートを
  開けます。新しいパッケージを展開して、
  古いフォルダーに上書きしてください。
  プログラムが自動でインストールを行う
  ことはありません。
・プログラムは 1 日に 1 回、自動でも確認を
  行い、新しいバージョンが公開されていれば
  通知でお知らせします。これをやめるには、
  「バージョン情報」ウィンドウで
  「アップデートを自動的に確認する」を
  オフにします。
・送信される内容: api.github.com への
  リクエスト 1 件だけです。GitHub に
  伝わるのは IP アドレスと
  「MirrorDock/<バージョン>」という名前で、
  ユーザーや PC に関する情報は
  含まれません。Windows が従量制課金接続
  として扱っている接続や、PC の
  インターネット通信が iPhone を経由して
  いるあいだは、自動での確認を行いません。
・メニューの「バージョン情報…」を選ぶと、
  専用のウィンドウが開きます。タブは
  3 つあります。
    バージョン情報  バージョンとリリース日、
                    アップデートの確認、
                    プロジェクト、
                    このガイド、ライセンスの
                    全文へのリンク
    この PC         この PC のうちプログラムに
                    関わる点を、項目ごとに
                    表示する: Windows、
                    ディスプレイ、電源、
                    ネットワーク、
                    ファイアウォール、
                    プロセッサ、メモリ、
                    GPU とその映像のデコード、
                    音声、グラフィックス
                    ドライバー、Apple の USB
                    サポート、ケーブルで
                    つないだ iPhone。
                    各項目は「良好」「注意」
                    「問題あり」のいずれかで
                    評価され、良好でない
                    項目には、どう対処すれば
                    よいかが表示される
    コンポーネント  プログラムを構成している
                    すべてのライブラリと
                    ツール（バージョン、
                    日付、ライセンス付き）と、
                    プログラムの各バージョン
                    のリリース日
・「この PC」タブのスコアは、評価された
  項目のうち問題のないものの割合を、
  ミラーリングにとっての重要度で
  重み付けして求めたものです（最も重みが
  大きいのは映像のハードウェアデコード
  です）。PC の準備がどれだけ整っているかを
  示すもので、ベンチマークではありません。
・「レポートをコピー」を押すと、このタブの
  内容がプレーンテキストとして
  クリップボードにコピーされます。問題を
  報告するときに貼り付けてください。
  このタブの内容が PC の外に送られる
  ことはなく、シリアル番号やデバイス名が
  表示されたり保存されたりすることも
  ありません。
・「バージョン情報」ウィンドウで使えるキー:
  Tab でリンクやボタンのあいだを移動し、
  Enter で実行します。Ctrl+Tab でタブが
  切り替わり、Esc でウィンドウが閉じます。


9. 詳細オプション
-----------------
mirror_dock.exe のショートカットを作成し、
「リンク先」の後ろにオプションを追加します。
または、%USERPROFILE%\.uxplayrc に 1 行に
1 つずつ（マイナス記号は付けずに）
オプションを書きます。例:
    n リビングの PC
    fs

よく使うオプション:
  -n 名前        iPhone に表示される名前
  -nh            名前に「@コンピューター名」を
                 付けない
  -fs            全画面表示で起動する
  -mode モード   quality、balanced（既定）、
                 performance のいずれか。
                 省略すると、メニューで
                 最後に選んだモードを使う
  -crop auto     黒帯を自動でトリミングする
                 （off = トリミングなし）。
                 省略すると、メニューで
                 最後に選んだ設定を使う
  -gpu auto      デコードと表示に使う GPU:
                 auto（既定。ディスプレイを
                 駆動している GPU）、
                 integrated、discrete、
                 software
  -h264          H.264 だけを使う（既定では、
                 GPU がハードウェアで
                 デコードできる場合、
                 iPhone が H.265 を使う
                 ことがある）
  -s 幅x高さ     このストリーム解像度を
                 要求する（指定すると、
                 モードは解像度を変えない）
  -ui en         表示言語: auto（既定）、en、
                 zh-TW、zh-CN、ja、ko、es、
                 de、fr、vi、th、ru
  -vsync 20      音声を映像より 20 ミリ秒
                 遅らせて再生する（負の値も
                 指定可。口の動きとのずれの
                 微調整用）
  -vsync no      タイムスタンプによる同期を
                 無効にする（届きしだい再生）
  -pin           接続時に PIN の入力を求める
                 （PIN は通知に表示される）
  -nc            iPhone がミラーリングを
                 停止しても、最後の映像と
                 ウィンドウを残す
  -ca ファイル   音楽の再生中に、アルバムの
                 カバー画像をファイルに
                 保存する
  -d             トラブル調査用の詳細なログ
UxPlay のそのほかのオプションも、ほとんどが
そのまま使えます（コマンド プロンプトで
mirror_dock.exe -h を実行すると一覧が
表示されます）。GStreamer やほかの
プラットフォームを必要とする機能は、
このプログラムには含まれていません
（HLS 動画のキャスト、MP4 録画、
カバー画像の画面表示、RTP 転送、映像の
反転や回転、Bluetooth LE ビーコン）。
古い設定ファイルにこうしたオプションが
ある場合は、無視したことがログに記録され、
プログラムは通常どおり起動します。


10. 参考値
----------
2016 年製のノート PC 1 台（Core i7-6700HQ、
内蔵の Intel HD Graphics 530 がディスプレイ
を駆動、Windows 11）で測定した値です。
あくまで目安であり、PC によって異なります。
・起動から約 0.5 秒で接続を受けられる状態に
  なります（ダウンロードしたばかりの
  ファイルを初めて起動するときは、
  ウイルス対策ソフトがスキャンするあいだ
  遅くなります）。終了にかかる時間は
  約 0.05 秒です。
・H.265 のハードウェアデコードでミラーリング
  した場合、音声と映像のあいだの遅延は
  約 18 ミリ秒で落ち着き、同期した状態を
  保ちます。
・音声は WASAPI の低遅延モード、映像は DXGI
  のフリップモデルのスワップチェーンを使い、
  どちらも同じタイムラインを共有します。


11. 推奨事項
------------
・2 台のディスプレイでデスクトップを
  複製表示していて、リフレッシュレートが
  異なる場合（60 Hz と 50 Hz など）、
  Windows はどちらか一方にしか合わせない
  ため、もう一方では動きが少しぎこちなく
  なります。片方のディスプレイしか見ない
  場合は、「設定 > システム > ディスプレイ」
  で、そのディスプレイだけにデスクトップを
  表示するように設定してください。
・ノート PC は、電源につないだ状態で
  最もよく動作します。


12. トラブルシューティング
--------------------------
・iPhone の一覧に PC が表示されない:
  両方が同じ Wi-Fi ネットワークにつながって
  いて、ファイアウォールでプログラムが
  許可されている必要があります
  （セクション 1 を参照）。ファイアウォールや、
  「パブリック」に設定されたネットワークが
  妨げになっていないかは、
  「バージョン情報」ウィンドウの「この PC」
  タブで確認できます（セクション 8 を
  参照）。iPhone の Wi-Fi をいったんオフに
  して、もう一度オンにしてください。
・ケーブルをつないでいるのに USB が
  使われない: メニューの 2 行目にある
  USB の状態を確認します。
  「インターネット共有をオンにしてください」
  の場合は、iPhone でインターネット共有を
  オンにします。
  「ネットワークアダプターが無効」の場合は、
  「USB ネットワークアダプターを有効にする…」
  を選びます。「USB 優先」が選ばれている
  ことも確認してください。ミラーリング中は、
  それが終わるまで USB への切り替えは
  行われません。iPhone でミラーリングを
  停止し、もう一度 PC を選んでください。
・「Wi-Fi のみ」を選んだあと、iPhone が
  接続できない: iPhone が USB の経路を
  まだ覚えている可能性があります。
  iPhone でミラーリングを停止し、数秒
  待ってからもう一度 PC を選んでください。
  それでも直らない場合は、iPhone の Wi-Fi を
  いったんオフにしてからオンに戻します。
・音が出ない: コントロールバーの
  スピーカーボタンがミュートになって
  いないか確認します。次に、ログに 10 秒
  ごとに書き込まれる行の「audio」の数値を
  見ます（パケット、ピーク、再生した
  フレームの値が出ていれば、PC 側の音量
  またはミキサーが下げられています）。
・iPhone のドライバーを libusb に置き換え
  ないでください（Zadig などのツール）。
  Apple のドライバーが削除され、USB での
  ミラーリングができなくなります。
・口の動きと声が合わない: -vsync とミリ秒数
  で微調整します（正の値 = 音声が遅れる）。
・F8 を押すと「iPhone を操作できません」と
  表示される: 原因は通知に表示されます。
  USB ケーブルをつなぎ、iPhone でこの PC を
  信頼します。デベロッパモードをオンに
  します（セクション 5 を参照）。iPhone には
  iOS 27 以降が必要です。開発者向け
  ディスクイメージのインストールには、PC の
  インターネット接続が必要です。詳細はログに
  記録されています。
・映像がカクつく: まず「パフォーマンス優先」
  モードを試してください。ディスプレイを
  複製表示している場合は、セクション 11 を
  ご覧ください。
・映像が真っ黒になり、プログラムがひとりでに
  再起動する: グラフィックスドライバーが
  リセットまたは更新されました。プログラムは
  1 回だけ再起動するので、iPhone でもう一度
  PC を選んでください。短時間に何度も
  起こる場合は、プログラムが停止して原因を
  表示します。グラフィックスドライバーを
  確認してください。


13. UxPlay for Windows（1.6 以前）からの移行
--------------------------------------------
・プログラムの名前は MirrorDock になり、
  実行ファイルは mirror_dock.exe です。
  新しいプログラムを起動する前に、古い
  uxplay.exe を終了してください。古い
  実行ファイルは削除して構いません。
・iPhone の「画面ミラーリング」に表示される
  名前は、「UxPlay@コンピューター名」から
  「MirrorDock@コンピューター名」に
  変わります。以前の名前のまま使うには、
  -n UxPlay を追加します。
・これまでの設定（USB 優先 / Wi-Fi のみ、
  モード、ウィンドウのサイズなど）は、
  初回の起動時に引き継がれます。
  「Windows 起動時に実行」がオンだった
  場合は、新しい実行ファイルに
  切り替えられます。
・ログのフォルダーは
  %LOCALAPPDATA%\MirrorDock になりました
  （古いフォルダーは、使用中のプログラムが
  なければ、名前を変えてそのまま使われます。
  古いログファイルはその中に残ります）。
・設定ファイル %USERPROFILE%\.uxplayrc と
  ペアリング鍵のファイルは、名前が
  変わらず、引き続き使えます。
