MirrorDock 사용 설명서
======================

MirrorDock은 iPhone이나 iPad의 화면과 소리를
Wi-Fi 또는 USB 케이블을 통해 Windows PC에서
보여 주고 들려주는 프로그램입니다. PC의
마우스와 키보드로 iPhone을 제어할 수도
있습니다(5번 항목 참고). 파일은
mirror_dock.exe 하나뿐이며, 따로 설치할
것이 없습니다.
(버전 1.6까지는 ‘UxPlay for Windows’라는
이름이었습니다. 이전 버전에서 업그레이드하는
경우 마지막 항목을 참고하세요.)

요구 사항: Windows 10 또는 11(x64).
프로그램은 실행되는 PC에 맞춰 스스로
조정됩니다. 모니터를 구동하는 그래픽
카드를 사용하고(내장 그래픽이든 외장
그래픽이든, Intel, AMD, NVIDIA 모두
가능하며, 그래픽 카드가 영상을 디코딩하지
못하면 소프트웨어 디코딩을 사용합니다),
모니터의 해상도와 주사율을 읽어 오며
(모니터를 연결하거나 분리하는 것도
알아차립니다), 오디오 장치가 지원하는
가장 짧은 지연을 사용합니다. 다른 PC로
옮겨도 다시 설정할 것이 없습니다.


1. 시작과 종료
--------------
- mirror_dock.exe를 두 번 클릭합니다. 콘솔
  창은 열리지 않습니다. 알림 영역(시계 옆)에
  아이콘이 나타나고, 처음 실행할 때는
  ‘준비 완료’ 알림이 표시됩니다. iPhone이
  연결되기 전에는 창이 없으며, 모든 기능은
  이 아이콘의 메뉴에 있습니다(왼쪽 클릭과
  오른쪽 클릭 모두 메뉴를 엽니다).
- 약 0.5초 안에 iPhone의 ‘화면 미러링’
  목록에 PC가 나타납니다.
- ‘Windows 보안 경고’가 나타나면 ‘허용’을
  선택합니다(가정용 네트워크는
  ‘개인 네트워크’입니다). 이때 취소했다면
  iPhone이 PC를 찾지 못합니다.
  ‘Windows 보안 > 방화벽 및 네트워크 보호 >
  방화벽에서 앱 허용’을 열고
  mirror_dock.exe에 체크하세요.
- 같은 이름으로는 하나만 실행됩니다.
  프로그램을 다시 시작해도, 실행 중이던
  프로그램이 ‘이미 실행 중입니다’ 알림을
  표시할 뿐입니다.
- 영상 창을 닫으면 해당 미러링만 끝납니다.
  프로그램은 백그라운드에서 다음 연결을
  계속 기다립니다.
- 종료하려면 알림 영역 아이콘의 메뉴에서
  ‘종료’를 선택합니다(iPhone에 알려지고,
  iPhone의 목록에서 PC가 사라집니다).
- Windows와 함께 시작하려면 메뉴에서
  ‘Windows 시작 시 실행’을 선택합니다
  (다시 선택하면 꺼집니다. 현재 사용자
  계정에만 설정되며 관리자 권한은 필요
  없습니다).
- 프로그램을 시작할 수 없으면(포트가 이미
  사용 중이거나 옵션을 잘못 적은 경우)
  원인과 로그 파일 위치를 알려 주는
  대화 상자가 표시됩니다.


2. Wi-Fi로 미러링하기
---------------------
iPhone과 PC를 같은 Wi-Fi 네트워크에 연결한
다음, iPhone에서 ‘제어 센터 > 화면 미러링’을
열고 ‘MirrorDock@컴퓨터이름’을 선택합니다.
영상 창이 나타나 맨 앞으로 올라옵니다.
iPhone을 잠그면 iOS가 화면은 일시 정지하고
소리는 계속 재생하며, 잠금을 풀면 화면이
다시 이어집니다(정상적인 동작입니다).
이 방법은 드라이버가 필요 없고 셀룰러
데이터도 쓰지 않습니다.


3. USB 케이블로 미러링하기
--------------------------
AirPlay는 iPhone이 USB 케이블을 통해
제공하는 네트워크 연결 위에서 동작합니다.
이 연결이 있으면 MirrorDock은 그쪽을 먼저
사용하고, 케이블을 뽑으면 Wi-Fi로
돌아갑니다. 프로그램이 실행 중일 때는
케이블을 꽂거나 뽑으면 약 2초 안에
반영됩니다(진행 중인 미러링은 끊기지
않으며, 그 미러링이 끝날 때 전환됩니다).

  1. Apple USB 드라이버를 설치합니다
     (한 번만). 함께 들어 있는
     install_apple_usb_support.cmd를
     실행하거나(winget으로
     Apple Mobile Device Support를
     설치합니다), Microsoft Store에서
     ‘Apple 기기’를 설치합니다.
  2. iPhone에서 ‘설정 > 개인용 핫스팟’으로
     이동해 ‘다른 사람의 연결 허용’을 켠
     다음 USB 케이블을 연결합니다.
     Windows에
     ‘Apple Mobile Device Ethernet’이라는
     네트워크 어댑터(172.20.10.x)가
     생깁니다. iPhone을 연결했는데 핫스팟이
     꺼져 있으면 약 8초 뒤에 알림으로 알려
     줍니다(실행할 때마다 한 번).
  3. iPhone에서 ‘제어 센터 > 화면 미러링 >
     MirrorDock’을 선택합니다.
     컨트롤 바와 알림 영역 아이콘에는
     실제로 사용 중인 연결에 따라 ‘USB’
     또는 ‘Wi-Fi’가 표시됩니다.
  메뉴의 둘째 줄에는 USB 연결 상태가
  표시됩니다: 연결되지 않음 /
  개인용 핫스팟을 켜세요 / 준비 완료 /
  네트워크 어댑터 비활성화됨 / 충전 전용.

USB와 Wi-Fi 전환(케이블은 충전을 위해 계속
꽂아 두어도 됩니다):
  컨트롤 바나 메뉴에서 둘 중 하나를
  선택합니다.
    - ‘USB 우선’: iPhone이 연결되어 있고
      개인용 핫스팟이 켜져 있으면 USB를
      사용합니다(기본값).
    - ‘Wi-Fi 전용’: 미러링에 항상 Wi-Fi를
      사용하며, 케이블은 충전만 합니다.
  선택한 내용은 기억됩니다. 미러링 도중에
  전환하면 그 미러링은 종료되므로,
  iPhone의 ‘화면 미러링’에서 PC를 다시
  선택하세요.

  ‘Wi-Fi 전용’은 USB를 확실하게 막습니다.
  프로그램은 USB 연결에서 응답하지 않으며,
  그런데도 USB로 들어오는 연결은
  거부합니다. 따라서 전환하려고 기기나
  네트워크 어댑터를 비활성화할 필요가
  없습니다(비활성화하지 마세요. USB
  미러링이 되지 않고, 케이블에 따라서는
  충전도 멈춥니다). 이전에
  ‘Apple Mobile Device Ethernet’을
  비활성화한 적이 있다면, ‘USB 우선’을
  선택할 때 프로그램이 알려 줍니다.
  알림(또는 ‘USB 네트워크 어댑터 활성화…’)을
  클릭하고 관리자 권한 확인 창에서 ‘예’를
  선택하세요.

셀룰러 데이터에 관하여:
- 미러링 자체는 iPhone에서 PC로 케이블을
  통해 이루어지는 로컬 전송입니다.
  통신사를 거치지 않으며 셀룰러 데이터를
  쓰지 않습니다.
- 다만 개인용 핫스팟이 켜져 있는 동안에는
  Windows가 PC의 인터넷 트래픽을 iPhone의
  셀룰러 데이터로 보낼 수 있습니다(보통
  집의 Wi-Fi에 IPv6가 없고 iPhone이
  통신사의 IPv6를 제공할 때 일어납니다).
- 프로그램이 이를 알아차리면 알림을
  표시합니다. 알림(또는
  ‘셀룰러 데이터 절약…’)을 클릭하고 관리자
  권한 확인 창에서 ‘예’를 선택하세요.
  한 번만 하면 됩니다. 그 뒤로는 케이블로
  미러링만 전송되고, PC는 원래 쓰던
  네트워크를 계속 사용합니다. Wi-Fi가
  끊겨도 PC가 iPhone의 데이터로 넘어가지
  않습니다.
- iPhone의 ‘셀룰러 데이터’는 켜 두세요.
  끄면 케이블의 로컬 연결을 포함해 개인용
  핫스팟까지 함께 사라져 USB 미러링이
  멈춥니다.
- 나중에 PC가 케이블을 통해 iPhone의
  인터넷을 다시 쓰게 하려면, 관리자
  권한으로 실행한 명령 프롬프트에서
  되돌립니다(<n>은 Apple 어댑터의
  인터페이스 번호이며,
  ‘netsh interface ipv4 show interfaces’로
  확인할 수 있습니다).
    netsh interface ipv4 set interface <n> ignoredefaultroutes=disabled
    netsh interface ipv6 set interface <n> routerdiscovery=enabled ignoredefaultroutes=disabled

참고: iOS 16부터 Apple은 예전의 ‘QuickTime’
유선 화면 캡처(핫스팟이 필요 없던 방식)를
비활성화했습니다. 그래서 이 프로그램은 그
방식을 사용하지 않으며, 위에서 설명한
방법이 현재 iOS에서 동작하는 유선
미러링입니다.


4. 창, 컨트롤 바, 전체 화면
---------------------------
- 창 크기: iPhone이 세로 방향이면 창은 화면
  높이의 약 90%가 되고, 가로로 돌리면 화면
  너비의 절반 정도가 되어 화면을 거의 다
  채우는 일은 없습니다. 창 테두리를 끌면
  크기를 바꿀 수 있고, 영상의 비율은
  유지됩니다. 직접 정한 크기와 위치는 세로
  방향과 가로 방향에 대해 따로 기억됩니다.
- 영상 위에서 마우스를 움직이면 아래쪽에
  컨트롤 바가 나타납니다. 3초 동안 움직임이
  없으면 숨겨집니다(포인터가 컨트롤 바
  위에 있을 때는 숨겨지지 않습니다).
- 컨트롤 바 왼쪽: USB 또는 Wi-Fi, 그리고
  영상 해상도.
  오른쪽: ‘USB 우선 | Wi-Fi 전용’, 음소거
  (이 프로그램의 소리만 끄며 iPhone의
  음량은 바뀌지 않습니다), 더 보기(전체
  메뉴), 전체 화면.
  필요할 때는 노란색 버튼
  ‘셀룰러 데이터 절약’, ‘USB 어댑터 활성화’가
  나타납니다.
- 영상 위 아무 곳이나 오른쪽 클릭해도
  전체 메뉴가 열립니다.
- 전체 화면: 영상을 두 번 클릭하거나 F,
  F11 또는 Alt+Enter를 누릅니다. Esc를
  누르면 해제됩니다. 전체 화면에서는 3초
  동안 움직임이 없으면 포인터와 컨트롤 바가
  함께 숨겨집니다.
- 검은 여백 자르기: iPhone 화면이 영상보다
  넓으면(예: iPhone에서 16:9 영화를 전체
  화면으로 재생할 때) iPhone은 검은
  부분까지 포함한 화면 전체를
  미러링합니다. 이 여백을 잘라내 창의 네
  변을 영상에 딱 맞출 수 있습니다.
    자동: C를 누르거나 메뉴에서
          ‘검은 여백 자동으로 자르기’를
          선택합니다. 영상 주위의 검은
          여백을 잘라내고, 창이 그에 맞게
          줄어듭니다. 다음 영화로 넘어가도
          자르기는 그대로 유지됩니다. 여백
          자리에 다른 무언가가 나타나 계속
          남아 있으면(예: 전체 화면 재생을
          끝냈을 때) 약 1초 안에 전체 영상이
          다시 표시됩니다. 어두운 장면을
          여백으로 착각하지 않도록, 양쪽이
          같고 약 1.5초 동안 이어지며
          움직이는 영상을 둘러싼 여백만
          잘라냅니다. 이 선택은 기억됩니다.
    수동: X를 누르거나 메뉴에서
          ‘표시할 영역 선택…’을 선택합니다.
          포인터가 십자 모양으로 바뀌면
          남길 부분을 드래그해 틀을 그리고
          버튼을 놓습니다. Esc나 마우스
          오른쪽 버튼으로 취소합니다.
          직접 그린 틀은 현재 영상에만
          적용되며, iPhone을 회전하거나
          다시 연결하면 사라집니다.
    해제: 메뉴에서 ‘자르지 않음’을
          선택합니다(자동 모드에서는 C를
          다시 눌러도 됩니다).
- 항상 위에 표시: T를 누르거나 메뉴에서
  ‘항상 위에 표시’를 선택합니다.
  음소거: M을 누릅니다.
- 미러링하는 동안에는 PC가 저절로 절전
  모드로 들어가거나 화면을 끄지 않습니다.
- 인터페이스는 Windows 표시 언어를
  따릅니다: 영어, 중국어 번체, 중국어 간체,
  일본어, 한국어, 스페인어, 독일어,
  프랑스어, 베트남어, 태국어. 그 밖의
  언어에서는 영어로 표시됩니다. 언어를
  고정하려면 -ui 옵션을 사용하세요
  (8번 항목 참고).


5. 마우스와 키보드로 iPhone 제어하기
------------------------------------
iPhone이 USB 케이블로 연결되어 있으면,
영상 위에서 하는 동작을 iPhone에서 그대로
실행할 수 있습니다. F8을 누르거나 메뉴에서
‘마우스와 키보드로 iPhone 제어’를
선택하세요. 켜져 있는 동안에는 창 제목에
‘제어 중’이 표시되며, F8을 다시 누르면
꺼집니다. 이 선택은 기억됩니다.

  왼쪽 버튼    손가락 하나의 동작. 클릭은
               탭, 누르고 있으면 길게 터치,
               드래그는 쓸어넘기기
  마우스 휠    포인터 아래의 내용을 스크롤
               (Shift를 누르면 좌우로)
  가운데 버튼  홈 화면으로 이동
  키보드       iPhone에 키보드를 연결한
               것처럼 입력됨. Ctrl은
               Command 키 역할을 하며,
               Ctrl+Space는 iPhone의
               입력 언어를 전환함
  Page Down, Page Up, Alt + 방향키
               다음 또는 이전 페이지나
               동영상으로 빠르게 쓸어넘김
               (키 입력을 받지 않는 앱용)
  오른쪽 버튼  평소처럼 MirrorDock 메뉴 열기

F8, F11, Alt+Enter, Alt+F4, 그리고 전체
화면에서의 Esc는 그대로 창에서 동작합니다.
제어가 켜져 있는 동안에는 컨트롤 바가
나타나지 않습니다. iPhone 화면의 아랫부분을
가리기 때문입니다. 메뉴는 마우스 오른쪽
버튼으로 여세요.

필요한 조건:
- iOS 27 이상인 iPhone이 USB 케이블로
  연결되어 있고, iPhone에서 이 PC를 신뢰한
  상태여야 합니다(iPhone이 물으면 잠금을
  해제하고 ‘신뢰’를 탭하세요). 케이블은
  제어에만 쓰입니다. 영상은 계속 Wi-Fi로
  받아도 되고, ‘Wi-Fi 전용’을 선택한 채로
  두어도 됩니다.
- 개발자 모드가 켜져 있어야 합니다.
  iPhone의 ‘설정 > 개인정보 보호 및 보안 >
  개발자 모드’에서 켭니다. 이 스위치는
  개발 도구가 요청하기 전까지 숨겨져
  있으며, F8을 처음 누를 때 MirrorDock이
  그 요청을 보냅니다. 켜면 iPhone이
  재시동되고 한 번 더 확인을 요청합니다.
- 처음 사용할 때, 그리고 iOS를 업데이트한
  뒤 처음 사용할 때마다 PC가 인터넷에
  연결되어 있어야 합니다. MirrorDock이
  Apple의 개발자 디스크 이미지
  (Developer Disk Image)를 iPhone에
  설치하기 때문이며, 1분 정도 걸립니다.
  MirrorDock은 이 이미지를 내려받고(약 17MB,
  %LOCALAPPDATA%\MirrorDock\developer_disk_image에
  보관됩니다) Apple의 서명 서비스에 이
  iPhone용으로 서명해 달라고 요청합니다.
  이때 Xcode와 마찬가지로 iPhone의 칩 식별
  번호가 Apple에 전달됩니다. 그 뒤로는
  제어할 때 어디에도 접속하지 않습니다.

이렇게 하는 이유: AirPlay에는 iPhone으로
입력을 전달하는 통로가 없습니다. 그래서
제어에는 iOS의 개발자 서비스를 이용합니다.
Apple의 Xcode가 실제 기기를 다룰 때 쓰는
바로 그 서비스입니다. 개발자 모드는 이
서비스를 위해 Apple이 직접 마련한
스위치입니다. iPhone을 탈옥시키는 것이
아니며, 같은 곳에서 다시 끌 수 있습니다.


6. 화질 및 성능 모드
--------------------
메뉴에서 세 가지 중 하나를 선택합니다.
선택한 모드는 기억됩니다.
  - ‘화질 우선’: iPhone에 전체 해상도를
    요청하고, 버퍼링을 조금 더 두며,
    프레임을 건너뛰지 않습니다. 영화,
    슬라이드, 텍스트에 적합합니다. 지연은
    ‘균형’보다 조금 깁니다.
  - ‘균형(자동 조정)’: 기본값입니다.
    모니터, 그래픽 카드, 네트워크에 맞춰
    끊김이 없는 범위에서 지연을 최대한
    짧게 유지합니다. 그래픽 카드가 영상을
    하드웨어로 디코딩하지 못하면 더 가벼운
    스트림을 요청합니다.
  - ‘성능 우선’: 더 가벼운 스트림(최대
    1920x1080)을 요청하고, 버퍼링을
    최소화하며, 너무 늦게 도착한 프레임은
    최신 프레임으로 바꿉니다. 지연이 가장
    짧고 메모리와 그래픽 부하가 가장
    적어서, 게임이나 오래된 PC에 적합합니다.
지연과 부드러움은 즉시 바뀝니다. 스트림
해상도는 연결할 때 iPhone이 정하므로,
해상도 변경(그리고 ‘화질 우선’의 더 깊은
버퍼링)은 다음 연결부터 완전히 적용됩니다
(프로그램이 이를 알려 줍니다).


7. 로그 파일과 충돌 기록
------------------------
- %LOCALAPPDATA%\MirrorDock\mirror_dock.log
  (메뉴의 ‘로그 파일 열기’). 모든 줄에
  시간이 기록됩니다. 이전 실행의 로그는
  mirror_dock.previous.log로 보관되며,
  파일 하나는 최대 8MB입니다.
- 10초마다 영상과 소리의 통계가 한 줄씩
  기록됩니다. 소리가 나지 않거나 영상이
  매끄럽지 않을 때 어디에 문제가 있는지
  여기서 알 수 있습니다.
- 프로그램이 비정상적으로 종료되면 같은
  폴더에 mirror_dock_crash.txt(발생 위치)와
  mirror_dock_crash.dmp가 남습니다. 문제를
  보고할 때 함께 첨부해 주세요.
- 명령 프롬프트에서 mirror_dock.exe를
  시작하면 로그가 그 창에 출력됩니다.


8. 고급 옵션
------------
mirror_dock.exe의 바로 가기를 만들고
‘대상’ 뒤에 옵션을 추가하거나,
%USERPROFILE%\.uxplayrc에 한 줄에 하나씩
(빼기 기호 없이) 옵션을 적습니다. 예:
    n 거실 PC
    fs

자주 쓰는 옵션:
  -n 이름        iPhone에 표시되는 이름
  -nh            이름 뒤에 @컴퓨터이름을
                 붙이지 않음
  -fs            전체 화면으로 시작
  -mode 모드     quality, balanced(기본값),
                 performance 중 하나.
                 지정하지 않으면 메뉴에서
                 마지막으로 고른 모드 사용
  -crop auto     검은 여백 자동으로 자르기
                 (off = 자르지 않음).
                 지정하지 않으면 메뉴에서
                 마지막으로 고른 설정 사용
  -gpu auto      디코딩과 표시에 쓸 GPU:
                 auto(기본값, 모니터를
                 구동하는 GPU),
                 integrated, discrete,
                 software
  -h264          H.264만 사용(기본적으로는
                 그래픽 카드가 하드웨어로
                 디코딩할 수 있으면
                 iPhone이 H.265를 쓸 수
                 있음)
  -s 가로x세로   이 스트림 해상도를 요청
                 (그러면 모드가 해상도를
                 바꾸지 않음)
  -ui en         인터페이스 언어:
                 auto(기본값), en, zh-TW,
                 zh-CN, ja, ko, es, de,
                 fr, vi, th
  -vsync 20      소리를 영상보다 20밀리초
                 늦게 재생(음수도 가능,
                 입 모양 미세 조정용)
  -vsync no      타임스탬프 동기화를 끔
                 (도착하는 대로 재생)
  -pin           연결하려면 PIN을 입력해야
                 함(PIN은 알림에 표시됨)
  -nc            iPhone이 미러링을 중단해도
                 마지막 화면과 창을 유지
  -ca 파일       음악을 재생하는 동안 앨범
                 표지를 파일로 저장
  -d             문제 해결용 상세 로그
그 밖의 UxPlay 옵션도 대부분 그대로
동작합니다(명령 프롬프트에서
mirror_dock.exe -h를 실행하면 목록이
나옵니다). GStreamer나 다른 플랫폼이
필요한 기능은 이 프로그램에 들어 있지
않습니다(HLS 동영상 캐스팅, MP4 녹화,
화면에 앨범 표지 표시, RTP 전달, 영상
뒤집기와 회전, Bluetooth LE 비콘). 예전
설정 파일에 이런 옵션이 있으면, 무시했다는
내용이 로그에 기록되고 프로그램은
정상적으로 시작됩니다.


9. 참고 수치
------------
2016년형 노트북 한 대(Core i7-6700HQ, 내장
Intel HD Graphics 530이 모니터를 구동,
Windows 11)에서 측정한 값입니다. 참고용일
뿐이며 PC마다 다릅니다.
- 실행 후 약 0.5초면 연결을 받을 준비가
  됩니다(새로 내려받은 파일을 처음 실행할
  때는 백신 프로그램이 검사하는 동안 더
  느립니다). 종료에는 약 0.05초가 걸립니다.
- 하드웨어 H.265 디코딩으로 미러링할 때
  소리와 영상 사이의 지연은 약 18밀리초에서
  안정되며, 동기화가 유지됩니다.
- 소리는 WASAPI 저지연 모드를, 영상은 DXGI
  플립 모델 스왑 체인을 사용하며, 둘은
  하나의 타임라인을 공유합니다.


10. 권장 사항
-------------
- 두 모니터가 바탕 화면을 복제해 표시하는데
  주사율이 서로 다르면(예: 60Hz와 50Hz)
  Windows는 그중 하나만 따르므로, 다른
  모니터에서는 움직임이 약간 고르지
  않습니다. 한 모니터만 본다면
  ‘설정 > 시스템 > 디스플레이’에서 그
  모니터에만 바탕 화면을 표시하도록
  설정하세요.
- 노트북은 전원에 연결했을 때 가장 잘
  동작합니다.


11. 문제 해결
-------------
- iPhone 목록에 PC가 나타나지 않음: 둘 다
  같은 Wi-Fi 네트워크에 있어야 하고
  방화벽이 프로그램을 허용해야 합니다
  (1번 항목 참고). iPhone의 Wi-Fi를 껐다가
  다시 켜세요.
- 케이블을 연결했는데 USB를 쓰지 않음:
  메뉴 둘째 줄의 USB 상태를 확인하세요.
  ‘개인용 핫스팟을 켜세요’라면 iPhone에서
  개인용 핫스팟을 켭니다.
  ‘네트워크 어댑터 비활성화됨’이라면
  ‘USB 네트워크 어댑터 활성화…’를
  선택합니다. ‘USB 우선’이 선택되어 있는지도
  확인하세요. 미러링 중에는 그 미러링이
  끝나야 USB로 전환되므로, iPhone에서
  미러링을 중단하고 PC를 다시 선택하세요.
- ‘Wi-Fi 전용’을 선택한 뒤 iPhone이
  연결하지 못함: iPhone이 아직 USB 경로를
  기억하고 있을 수 있습니다. iPhone에서
  미러링을 중단하고 몇 초 기다린 뒤 PC를
  다시 선택하세요. 그래도 안 되면 iPhone의
  Wi-Fi를 껐다가 켜세요.
- 소리가 나지 않음: 컨트롤 바의 스피커
  버튼이 음소거로 되어 있는지 확인한 다음,
  로그에 10초마다 기록되는 줄의 ‘audio’
  수치를 봅니다(패킷, 피크, 재생된 프레임
  값이 있으면 PC 자체의 음량이나 믹서가
  낮춰져 있다는 뜻입니다).
- iPhone 드라이버를 libusb로 바꾸지
  마세요(Zadig 같은 도구). Apple 드라이버가
  제거되어 USB 미러링이 동작하지 않게
  됩니다.
- 입 모양과 목소리가 맞지 않음: -vsync와
  밀리초 값으로 미세하게 조정하세요
  (양수 = 소리를 늦춤).
- F8을 누르면
  ‘iPhone을 제어할 수 없습니다’라고 표시됨:
  원인은 알림에 나와 있습니다. USB 케이블을
  연결하고 iPhone에서 이 PC를 신뢰하세요.
  개발자 모드를 켜세요(5번 항목 참고).
  iPhone은 iOS 27 이상이어야 합니다. 개발자
  디스크 이미지를 설치하려면 PC가 인터넷에
  연결되어 있어야 합니다. 자세한 내용은
  로그에 있습니다.
- 영상이 끊김: 먼저 ‘성능 우선’ 모드를
  써 보세요. 모니터를 복제해 쓰는 경우에는
  10번 항목을 참고하세요.
- 화면이 검게 변하고 프로그램이 저절로 다시
  시작됨: 그래픽 드라이버가 재설정되었거나
  업데이트되었습니다. 프로그램은 한 번
  다시 시작하므로 iPhone에서 PC를 다시
  선택하세요. 짧은 시간 안에 여러 번
  반복되면 프로그램이 멈추고 원인을
  표시합니다. 그래픽 드라이버를
  확인하세요.


12. UxPlay for Windows(1.6 이하)에서 업그레이드
-----------------------------------------------
- 프로그램 이름이 MirrorDock으로 바뀌었고
  실행 파일은 mirror_dock.exe입니다. 새
  프로그램을 시작하기 전에 예전
  uxplay.exe를 종료하세요. 예전 실행 파일은
  삭제해도 됩니다.
- iPhone의 ‘화면 미러링’에 표시되는 이름이
  ‘UxPlay@컴퓨터이름’에서
  ‘MirrorDock@컴퓨터이름’으로 바뀝니다.
  예전 이름을 유지하려면 -n UxPlay를
  추가하세요.
- 기존 설정(USB 우선 / Wi-Fi 전용, 모드, 창
  크기 등)은 처음 시작할 때 그대로
  옮겨집니다. ‘Windows 시작 시 실행’이 켜져
  있었다면 새 실행 파일로 바뀝니다.
- 로그 폴더는 이제
  %LOCALAPPDATA%\MirrorDock입니다(예전
  폴더는 사용 중인 프로그램이 없으면
  이름만 바꿔 그대로 쓰며, 예전 로그
  파일은 그 안에 남습니다).
- 설정 파일 %USERPROFILE%\.uxplayrc와
  페어링 키 파일은 이름이 그대로이며 계속
  사용할 수 있습니다.
