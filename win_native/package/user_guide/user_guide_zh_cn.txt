MirrorDock 使用说明
===================

MirrorDock 可以把 iPhone 或 iPad 的画面和
声音投到 Windows 电脑上，走 Wi-Fi 或 USB
数据线都可以；还能用电脑的鼠标和键盘操作
iPhone（见第五节）。整个软件只有一个文件
mirror_dock.exe，不需要再安装别的东西。
（1.6 及更早的版本叫“UxPlay for Windows”；
从旧版升级请看最后一节。）

系统要求：Windows 10 或 11（x64）。软件会
根据所在的电脑自动适配：使用驱动显示器的
那块显卡（集成显卡或独立显卡，Intel、AMD、
NVIDIA 均可；显卡无法解码视频时改用软件
解码），读取显示器的分辨率和刷新率（接上
或拔掉显示器时会重新检测），并采用音频
设备支持的最低延迟。换一台电脑也不需要
重新设置。


一、启动与退出
--------------
- 双击 mirror_dock.exe。不会弹出控制台
  窗口；通知区域（时钟旁边）会出现一个
  图标，首次启动时还会显示“已就绪”通知。
  手机连接之前没有窗口：所有功能都在这个
  图标的菜单里（单击左键或右键均可打开）。
- 大约半秒之内，iPhone 的“屏幕镜像”列表里
  就能看到这台电脑。
- 如果弹出“Windows 安全中心警报”，请选择
  “允许”（家庭网络属于“专用网络”）。当时
  如果点了取消，iPhone 就找不到这台电脑：
  请打开“Windows 安全中心 > 防火墙和网络
  保护 > 允许应用通过防火墙”，勾选
  mirror_dock.exe。
- 同一个名称只运行一份：软件已在运行时
  再次启动，只会让正在运行的那一份显示
  “已在运行”通知。
- 关闭视频窗口只结束这一次镜像；软件仍在
  后台等待下一次连接。
- 退出软件：通知区域图标的菜单 >“退出”
  （软件会通知 iPhone，这台电脑也会从它的
  列表里消失）。
- 随 Windows 一起启动：菜单 >“开机自动启动”
  （再选一次即可关闭；只对你的用户账户
  生效，不需要管理员权限）。
- 如果软件无法启动（端口被占用、选项拼写
  有误），会弹出对话框说明原因，并给出
  日志文件的位置。


二、通过 Wi-Fi 镜像
-------------------
把 iPhone 和电脑连到同一个 Wi-Fi 网络，
然后在 iPhone 上打开 控制中心 > 屏幕镜像，
选择“MirrorDock@电脑名”。视频窗口会自动
出现并显示在最前面。手机锁屏时，iOS 会
暂停画面，声音继续播放；解锁后画面恢复
（这是正常现象）。
这种方式不需要驱动，也不消耗手机流量。


三、通过 USB 数据线镜像
-----------------------
原理是让 AirPlay 走 iPhone 在 USB 数据线上
提供的网络链路。只要这条链路存在，
MirrorDock 就优先用它；拔掉数据线则回到
Wi-Fi。软件运行期间，插拔数据线后约 2 秒
内就会跟着切换（正在进行的镜像不会被
打断：等它结束后才切换）。

  1. 安装 Apple 的 USB 驱动（只需一次）：
     运行随附的
     install_apple_usb_support.cmd（它会用
     winget 安装 Apple Mobile Device
     Support），或者从 Microsoft Store 安装
     “Apple 设备”。
  2. 在 iPhone 上：设置 > 个人热点 > 打开
     “允许其他人加入”，然后插上 USB
     数据线。Windows 里会多出一个名为
     “Apple Mobile Device Ethernet”的网卡
     （172.20.10.x）。如果 iPhone 已经插上
     但热点没开，大约 8 秒后会有通知提醒
     （每次运行只提醒一次）。
  3. 在 iPhone 上：控制中心 > 屏幕镜像 >
     MirrorDock。
     控制栏和通知区域图标会显示“USB”或
     “Wi-Fi”，以实际使用的链路为准。
  菜单的第二行显示 USB 链路的状态：
  未接入 / 请打开个人热点 / 已就绪 /
  网卡已禁用 / 仅充电。

在 USB 和 Wi-Fi 之间切换（数据线可以一直
插着充电）：
  在控制栏或菜单里二选一：
    - “USB 优先”：iPhone 插着数据线且个人
      热点开着时走 USB（默认）。
    - “仅 Wi-Fi”：镜像一律走 Wi-Fi，
      数据线只用来充电。
  软件会记住你的选择。镜像过程中切换会
  结束当前这次镜像：请在 iPhone 的
  “屏幕镜像”里重新选择这台电脑。

  “仅 Wi-Fi”会真正把 USB 挡在外面：软件
  不在 USB 链路上应答，仍然从这条链路进来
  的连接会被拒绝。所以切换时不需要去禁用
  设备或它的网卡（也请不要这样做：那会让
  USB 镜像失效，用某些数据线时还会中断
  充电）。如果之前禁用过“Apple Mobile
  Device Ethernet”，选择“USB 优先”时软件
  会提示：点击通知（或“启用 USB 网卡…”），
  并在管理员权限提示中选择“是”。

关于手机流量：
- 镜像本身是手机到电脑之间通过数据线进行
  的本地传输，不经过运营商，也不消耗手机
  流量。
- 但在个人热点开着的时候，Windows 可能会
  让电脑自己的上网流量走 iPhone 的蜂窝
  数据（常见于家里的 Wi-Fi 没有 IPv6、而
  iPhone 提供了运营商 IPv6 的情况）。
- 软件发现这种情况时会显示通知：点击通知
  （或“节省手机流量…”），并在管理员权限
  提示中选择“是”。只需设置一次。此后
  数据线只承载镜像，电脑上网仍走它自己的
  网络；即使 Wi-Fi 断开，电脑也不会改用
  手机的流量。
- iPhone 上的“蜂窝数据”请保持打开：关掉
  它，个人热点（包括数据线上的本地链路）
  也会一并消失，USB 镜像随之中断。
- 以后如果想让电脑重新通过数据线使用手机
  的网络，可以在管理员命令提示符中还原
  （<n> 是 Apple 网卡的接口编号，可用
  “netsh interface ipv4 show interfaces”
  查看）：
    netsh interface ipv4 set interface <n> ignoredefaultroutes=disabled
    netsh interface ipv6 set interface <n> routerdiscovery=enabled ignoredefaultroutes=disabled

说明：自 iOS 16 起，Apple 已停用旧的
“QuickTime”有线屏幕采集方式（不需要热点
的那种），所以本软件不使用它；上面介绍的
方法是在当前 iOS 上可用的有线镜像方式。


四、窗口、控制栏与全屏
----------------------
- 窗口大小：手机竖屏时，窗口约为屏幕高度
  的 90%；横屏时约为屏幕宽度的一半，而
  不是几乎占满整个屏幕。拖动窗口边框可以
  调整大小，画面比例保持不变。你选定的
  大小和位置会被记住，竖屏和横屏分别保存。
- 把鼠标移到画面上，底部会出现控制栏；
  鼠标 3 秒不动就自动隐藏（指针停在控制栏
  上时不会隐藏）。
- 控制栏左侧：USB 或 Wi-Fi，以及画面
  分辨率。
  右侧：“USB 优先 | 仅 Wi-Fi”、静音（只对
  本软件生效，不改变 iPhone 的音量）、更多
  （完整菜单）和全屏。
  需要时还会出现黄色按钮：“节省手机
  流量”、“启用 USB 网卡”。
- 在画面任意位置单击右键，也可以打开完整
  菜单。
- 全屏：双击画面，或按 F、F11、Alt+Enter；
  按 Esc 退出。全屏时鼠标 3 秒不动，指针
  和控制栏会一起隐藏。
- 裁剪黑边：手机屏幕比影片更宽时（例如在
  iPhone 上全屏播放 16:9 的影片），手机
  镜像的是整个屏幕，黑色区域也包括在内。
  可以把它们裁掉，让窗口四边都紧贴画面：
    自动：按 C，或在菜单中选择“自动裁剪
          黑边”。画面四周的黑边会被裁掉，
          窗口随之缩小到刚好容纳画面。
          一部影片接着另一部播放时，裁剪
          保持不变；如果黑边里出现了别的
          内容并且停留在那里（例如退出
          全屏播放），完整画面会在大约
          一秒内恢复。为了不把暗场景误判
          成黑边，只裁剪两侧对称、持续约
          1.5 秒、并且围着运动画面的
          黑边。这个选择会被记住。
    手动：按 X，或在菜单中选择“框选裁剪
          范围…”。指针变成十字后，拖出
          一个框圈住想保留的部分，松开
          即可。按 Esc 或鼠标右键取消。
          手动框选只对当前画面有效，手机
          旋转或重新连接后即失效。
    还原：在菜单中选择“不裁剪”（自动模式
          下再按一次 C 也可以）。
- 窗口置顶：按 T，或在菜单中选择“窗口
  置顶”。静音：按 M。
- 截图：按 F9，或在菜单中选择“截图”，或
  点控制栏上的相机按钮。画面会以手机发来
  的分辨率（不是窗口的大小）保存为 PNG
  文件，放在“图片”文件夹里的“MirrorDock”
  文件夹中（以日期和时间命名），同时复制
  到剪贴板；画面上方会出现一行字提示。操
  作 iPhone 期间 F9 同样有效。
- 镜像期间，电脑不会自行进入睡眠或关闭
  屏幕。
- 界面语言跟随 Windows 的显示语言：英语、
  繁体中文、简体中文、日语、韩语、
  西班牙语、德语、法语、越南语、泰语和
  俄语；其他语言一律显示英语。想固定
  使用某种语言，请用 -ui 选项（见第九节）。


五、用鼠标和键盘操作 iPhone
---------------------------
iPhone 插着 USB 数据线时，你在画面上的
操作会直接作用到手机上：按 F8，或在菜单中
选择“用鼠标和键盘操作 iPhone”。开启期间，
窗口标题会显示“可操作”；再按一次 F8 即可
关闭。这个选择会被记住。

  鼠标左键  一根手指：单击就是轻点，
            按住就是长按，拖动就是轻扫
  鼠标滚轮  滚动指针下方的内容（按住
            Shift：横向滚动）
  鼠标中键  回到主屏幕
  双击      照旧是进入 / 退出全屏（窗口
            自己的命令）。按住 Alt 再
            双击：在手机上轻点两下
  键盘      在手机上打字，就像给手机接了
            一把键盘。Ctrl 相当于
            Command 键；按 Ctrl+空格
            可切换手机的输入语言
  Page Down、Page Up、Alt + 方向键
            快速滑动到下一页或上一页、
            下一个或上一个视频（供不响应
            按键的 App 使用）
  鼠标右键  照旧是 MirrorDock 的菜单

操作开启期间，窗口自己的命令优先：F8、
F11、Alt+Enter、Alt+F4、全屏时的 Esc，以及
双击，仍然作用于窗口。双击时，第一下在
第二下到来之前就已经作为一次轻点传到手机
了：有黑边时请双击黑边，或者改按 F11。
操作开启期间控制栏不会出现，因为它会挡住
手机屏幕的底部：请改用鼠标右键。

操作开启期间延迟会变短。iPhone 给画面和
声音标上的时间，比它们实际送达的时刻晚一
点（走 Wi-Fi 时，画面大约晚 85 毫秒），
本软件平时会等到那个时间才播放。操作开启
期间，两者只要来得及就尽早播放，彼此仍然
同步，所以点下去之后的反应会更早出现在画
面上。切换时会用几秒钟平滑地过渡，声音不
会跳一下。

需要满足的条件：
- iPhone 运行 iOS 27 或更高版本，插着 USB
  数据线，并且已经信任这台电脑（手机询问
  时，解锁并轻点“信任”）。只有操作走
  数据线：画面仍然可以走 Wi-Fi，
  “仅 Wi-Fi”也可以保持选中。
- 打开开发者模式：在 iPhone 上前往 设置 >
  隐私与安全性 > 开发者模式。这个开关平时
  是隐藏的，要有开发工具提出请求才会
  出现；你第一次按 F8 时，MirrorDock 就会
  提出请求。打开后 iPhone 会重新启动，
  并再次请你确认。
- 第一次使用，以及每次 iOS 更新后的
  第一次，电脑需要能上网：MirrorDock 会给
  手机装上 Apple 的“开发者磁盘映像”，大约
  需要一分钟。它会下载映像（约 17 MB，
  保存在
  %LOCALAPPDATA%\MirrorDock\developer_disk_image），
  并请 Apple 的签名服务针对这部手机为
  映像签名；和 Xcode 一样，这个过程会把
  手机的芯片编号告诉 Apple。装好之后，
  操作不会再连接任何地方。

为什么这样做：AirPlay 没有把输入传给手机
的通道，所以操作改走 iOS 的开发者服务，
也就是 Apple 的 Xcode 用来操作真机的
那一套。开发者模式是 Apple 自己为这些
服务准备的开关；它不会让手机越狱，想关的
时候回到同一个地方关掉就行。


六、画质与性能模式
------------------
在菜单里三选一，软件会记住你的选择：
  - “画质优先”：向手机请求完整分辨率，多
    保留一点缓冲，不跳过任何一帧。适合看
    电影、幻灯片和文字。延迟比“均衡”
    略高。
  - “均衡（自动调整）”：默认模式。根据
    显示器、显卡和网络状况，在不卡顿的
    前提下把延迟压到最低；显卡不能硬件
    解码视频时，会请求更轻量的视频流。
  - “性能优先”：请求更轻量的视频流（最高
    1920x1080），把缓冲减到最少，来不及
    显示的帧直接换成最新的一帧。延迟
    最低，占用的内存和显卡资源最少：适合
    玩游戏，或者电脑比较旧的时候使用。
延迟和流畅度的变化立即生效。视频流的
分辨率是手机在连接时决定的，所以分辨率的
更改（以及“画质优先”更深的缓冲）要到下
一次连接才完全生效（软件会给出提示）。


七、日志文件与崩溃记录
----------------------
- %LOCALAPPDATA%\MirrorDock\mirror_dock.log
  （菜单中的“打开日志”）。每一行都带
  时间；上一次运行的日志保留为
  mirror_dock.previous.log；单个文件最大
  8 MB。
- 每 10 秒会写入一行画面和声音的统计
  信息。没有声音或画面不流畅时，可以从
  这里看出问题出在哪个环节。
- 如果软件异常退出，同一个文件夹里会留下
  mirror_dock_crash.txt（出错位置）和
  mirror_dock_crash.dmp；反馈问题时请一并
  附上。
- 从命令提示符启动 mirror_dock.exe 时，
  日志会直接输出在那里。


八、更新与“关于”窗口
--------------------
- 菜单里的“检查更新…”会向 GitHub 询问最
  新版本，并把结果显示在“关于”窗口里。有
  新版本时，“立即更新”会把它下载下来、验
  证，再替换正在运行的程序，然后程序自动
  重新启动。如果正在镜像，会等镜像结束才
  重新启动，或者等你点“立即重新启动”。
  “下载”照样会在浏览器中打开它的 zip 压
  缩包，让你自己解压、覆盖旧文件夹；“更
  新内容”会打开它的发行说明。你没有要
  求，就不会安装任何东西。
- 本软件每天会自己询问一次，有新版本时
  弹出通知。不需要的话，在“关于”窗口里
  关掉“自动检查更新”。
- 发送了什么：只有一个发往 api.github.com
  的请求。GitHub 能看到你的 IP 地址和名称
  “MirrorDock/<版本>”，除此之外没有任何
  关于你或这台电脑的信息。在 Windows 标记
  为按流量计费的连接上，或者电脑正通过
  iPhone 上网时，不会自动检查。
- 只会安装真正的版本：每个版本都用一把不
  放在网上的密钥签名，本软件内置它的公
  钥。签名对不上的更新包，不管从哪里来，
  都不会安装。如果本软件所在的文件夹无法
  写入，请改用“下载”。
- 菜单里的“关于…”会打开一个独立的窗口，
  共有三页：
    关于      版本和发布日期、检查更新，
              以及项目主页、本说明、
              许可证全文的链接
    这台电脑  这台电脑上与本软件有关的
              各项，一项一行：Windows、
              显示器、电源、网络、防火墙、
              处理器、内存、显卡及其视频
              解码、音频、显卡驱动、Apple
              的 USB 支持、插着数据线的
              iPhone。每一行都会评为
              良好、需要注意或有问题；
              不是良好的那一行，会写明
              该怎么处理
    组件      构建本软件所用的每一个库和
              工具，附版本、日期和许可证，
              以及本软件各个版本的发布
              日期
- “这台电脑”的评分，是参与评级的各行里
  没有问题的占多少，并按各项对镜像的重要
  程度加权（视频硬件解码的权重最大）。它
  反映的是这台电脑准备得好不好，不是跑分。
- “这台电脑”里不是良好的那一行，只要本软
  件能代劳，旁边就有按钮：让程序通过
  Windows 防火墙、启动 Apple 的服务、安
  装 Apple 的 USB 支持，或者打开 Windows
  “设置”里处理那件事的页面。需要管理员权
  限的部分，由 Windows 自己的工具在平时
  那个确认提示之后完成。回到这个窗口时，
  这一页会重新检查一次。
- “复制报告”会把这一页以纯文本的形式放到
  剪贴板，反馈问题时可以直接粘贴。这一页
  的内容不会离开这台电脑，也不会显示或
  保存任何序列号或设备名称。
- “关于”窗口里的按键：Tab 在链接和按钮
  之间移动，Enter 使用选中的一项，Ctrl+Tab
  换页，Esc 关闭窗口。


九、高级选项
------------
为 mirror_dock.exe 创建快捷方式，在“目标”
后面加上选项；或者在
%USERPROFILE%\.uxplayrc 里每行写一个选项
（不带减号），例如：
    n 客厅电脑
    fs

常用选项：
  -n 名称        在 iPhone 上显示的名称
  -nh            名称后面不加 @电脑名
  -fs            启动后直接全屏
  -mode 模式     quality（画质优先）、
                 balanced（均衡，默认）或
                 performance（性能优先）；
                 不指定时沿用菜单中上次
                 的选择
  -crop auto     自动裁剪黑边（off = 不
                 裁剪）；不指定时沿用
                 菜单中上次的选择
  -gpu auto      解码和显示所用的 GPU：
                 auto（默认：驱动显示器
                 的那块）、integrated
                 （集成显卡）、discrete
                 （独立显卡）、software
                 （纯软件）
  -h264          只使用 H.264（默认情况
                 下，显卡支持硬件解码时
                 iPhone 可以使用 H.265）
  -s 宽x高       请求指定的视频流分辨率
                 （指定后模式不再改动它）
  -ui en         界面语言：auto（默认）、
                 en、zh-TW、zh-CN、ja、
                 ko、es、de、fr、vi、th、ru
  -vsync 20      让声音比画面晚 20 毫秒
                 播放（可以为负数；用于
                 微调口型同步）
  -vsync no      关闭时间戳同步（收到就
                 播放）
  -pin           连接时必须输入 PIN（PIN
                 会显示在通知里）
  -nc            iPhone 停止镜像时保留
                 最后的画面和窗口
  -ca 文件       播放音乐时把专辑封面
                 保存到文件
  -d             输出详细日志，便于排查
                 问题
其余的 UxPlay 选项大多仍然可用（在命令
提示符中运行 mirror_dock.exe -h 可以
列出）。需要 GStreamer 或其他平台的功能
不包含在本软件中（HLS 视频投放、MP4 录制、
在屏幕上显示封面、RTP 转发、画面翻转或
旋转、蓝牙 LE 信标）。旧的设置文件里如果
有这类选项，日志中会注明已忽略，软件照常
启动。


十、参考数据
------------
以下数字是在一台 2016 年的笔记本电脑上
测得的（Core i7-6700HQ，由集成的 Intel HD
Graphics 530 驱动显示器，Windows 11），
仅供参考，不同电脑会有差异：
- 启动后约 0.5 秒即可接受连接（新下载的
  文件第一次启动时，会因为杀毒软件扫描而
  慢一些）；退出约需 0.05 秒。
- 使用 H.265 硬件解码镜像时：声音与画面
  之间的延迟稳定在约 18 毫秒，音画同步。
- 声音使用 WASAPI 低延迟模式，画面使用
  DXGI 翻转模型交换链，两者共用同一条
  时间轴。


十一、建议
----------
- 两台显示器复制同一个桌面而刷新率不同
  （例如 60 Hz 和 50 Hz）时，Windows 只会
  跟其中一台同步，另一台上的运动画面会
  略有顿挫。如果只看其中一台，请在
  “设置 > 系统 > 屏幕”中改为仅在那台
  显示器上显示桌面。
- 笔记本电脑接通电源时效果最好。


十二、疑难解答
--------------
- iPhone 的列表里找不到电脑：两者必须在
  同一个 Wi-Fi 网络中，并且防火墙要放行
  本软件（见第一节）；“关于”窗口的“这台
  电脑”页（见第八节）会告诉你，是不是
  防火墙或被设为“公用”的网络挡住了。把
  iPhone 的 Wi-Fi 关掉再打开。
- 插着数据线却没走 USB：看菜单第二行的
  USB 状态。显示“请打开个人热点”：在
  iPhone 上打开个人热点。显示“网卡已
  禁用”：选择“启用 USB 网卡…”。确认选中
  的是“USB 优先”。镜像进行中时，要等这次
  镜像结束才会切到 USB：在 iPhone 上停止
  镜像，再重新选择这台电脑。
- 选择“仅 Wi-Fi”后 iPhone 连不上：手机
  可能还记着 USB 那条路径。在 iPhone 上
  停止镜像，等几秒再重新选择这台电脑；
  仍然不行的话，把 iPhone 的 Wi-Fi 关掉
  再打开。
- 没有声音：先看控制栏的扬声器按钮是否
  显示为静音，再看日志里每 10 秒一行的
  “audio”数字（有数据包、有峰值、有已
  播放的帧，说明是电脑自身的音量或音量
  合成器被调低了）。
- 不要用 libusb 替换 iPhone 的驱动（Zadig
  之类的工具）：那会移除 Apple 的驱动，
  USB 镜像就不能用了。
- 口型和声音对不上：用 -vsync 加毫秒数
  微调（正数 = 声音延后）。
- 按 F8 后提示“无法操作 iPhone”：通知里会
  说明原因。插上 USB 数据线并信任这台
  电脑；打开开发者模式（见第五节）；
  iPhone 需要 iOS 27 或更高版本；安装
  开发者磁盘映像时电脑需要能上网。详细
  信息在日志里。
- 画面卡顿：先试试“性能优先”模式；使用
  复制显示器时请看第十一节。
- 画面变黑后软件自行重启：显卡驱动被重置
  或更新了。软件会自动重启一次，请在
  iPhone 上重新选择这台电脑。如果短时间
  内反复发生，软件会停止并显示原因：
  请检查显卡驱动。


十三、从 UxPlay for Windows（1.6 及更早版本）升级
-------------------------------------------------
- 软件现在叫 MirrorDock，可执行文件是
  mirror_dock.exe。请先退出旧的 uxplay.exe
  再启动新的；旧的可执行文件可以删除。
- iPhone 上“屏幕镜像”列表里的名称会从
  “UxPlay@电脑名”变成“MirrorDock@电脑名”。
  想沿用旧名称，请加上 -n UxPlay。
- 你的设置（USB 优先 / 仅 Wi-Fi、模式、
  窗口大小等）会在第一次启动时自动沿用；
  “开机自动启动”如果原来是打开的，也会改为
  启动新的可执行文件。
- 日志文件夹现在是
  %LOCALAPPDATA%\MirrorDock（旧文件夹没有
  被任何程序占用时，会直接改名沿用；里面
  的旧日志文件会保留）。
- 设置文件 %USERPROFILE%\.uxplayrc 和配对
  密钥文件的名称不变，可以继续使用。
