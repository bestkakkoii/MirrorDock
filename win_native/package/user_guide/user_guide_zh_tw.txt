MirrorDock 使用說明
===================

把 iPhone／iPad 的畫面與聲音投到 Windows 電腦：可走 Wi-Fi，也可走 USB
傳輸線。單一 mirror_dock.exe，不需要安裝其他元件。
（1.6 以前的名稱是「UxPlay for Windows」；從舊版升級請看最後一節。）

適用：Windows 10／11（x64）。程式會依「當下這台電腦」自動調整 —— 自動
選用驅動螢幕的那張顯示卡（內顯、獨顯，Intel／AMD／NVIDIA 都可以；不支援
硬體解碼時改用軟體解碼）、自動取得螢幕解析度與更新率（接上或拔掉外接
螢幕會即時重新偵測）、自動使用音訊裝置的最低延遲。換電腦不必重新設定。


一、啟動與結束
--------------
‧ 雙擊 mirror_dock.exe。不會出現黑色主控台視窗；右下角通知區域會出現圖示，
  第一次啟動時會跳出「已就緒」通知。在還沒有手機連線之前，程式沒有視窗，
  所有功能都在通知區域圖示的選單裡（按左鍵或右鍵都會開啟選單）。
‧ 約 0.5 秒內就能在 iPhone 的「螢幕鏡像輸出」清單看到這台電腦。
‧ 若跳出「Windows 安全性警訊」，請按「允許」（家用網路屬於「私人網路」）。
  當時若按了取消，iPhone 會找不到這台電腦：到「Windows 安全性 → 防火牆與
  網路保護 → 允許應用程式通過防火牆」，把 mirror_dock.exe 勾選起來。
‧ 同一個名稱只會執行一份：程式已經在執行時再開一次，只會由原本那一份跳出
  「已在執行中」的通知，不會開出第二份。
‧ 關閉畫面視窗只會中斷這次鏡像，程式仍在背景等待下一次連線。
‧ 結束程式：通知區域圖示的選單 →「結束」（會通知 iPhone 中斷，並把自己
  從鏡像清單移除）。
‧ 想要開機後自動執行：選單 →「開機時啟動」（再按一次取消；只寫入目前
  使用者的啟動項目，不需要系統管理員權限）。
‧ 啟動失敗（例如指定的連接埠被占用、選項寫錯）時會跳出對話框說明原因，
  並指出記錄檔的位置。


二、Wi-Fi 鏡像
--------------
iPhone 與電腦連同一個 Wi-Fi → 控制中心 →「螢幕鏡像輸出」→ 選
「MirrorDock@電腦名稱」。畫面視窗會自動出現並移到最前面。鎖定手機時 iOS 會
暫停畫面但聲音續播，解鎖即自動恢復（正常現象）。
這條路不需要安裝任何驅動，也不耗行動數據。


三、USB 投影（走傳輸線）
------------------------
做法是「在 iPhone 的 USB 網路上跑 AirPlay」。只要那條 USB 網路存在，
MirrorDock 會優先用它，拔掉線就回到 Wi-Fi；程式開著時插拔都會在約 2 秒內自動
切換（正在投影中則等這次投影結束才切換，不會打斷）。

  1. 安裝 Apple USB 驅動（只需一次）：執行隨附的
     install_apple_usb_support.cmd（用 winget 安裝 Apple Mobile Device
     Support），或從 Microsoft Store 安裝「Apple 裝置」。
  2. iPhone：設定 → 個人熱點 → 打開「允許其他人加入」，接上 USB 線。
     Windows 會多出一張「Apple Mobile Device Ethernet」網路卡（172.20.10.x）。
     iPhone 接上但熱點沒開時，約 8 秒後會跳通知提醒（每次執行只提醒一次）。
  3. iPhone 控制中心 →「螢幕鏡像輸出」→ 選 MirrorDock。
     控制列與通知區域圖示會依實際走的路顯示「USB」或「Wi-Fi」。
  選單第二行是 USB 狀態：未接上／請開啟個人熱點／已就緒／網路卡已停用／
  僅充電。

切換 USB／Wi-Fi（線可以一直接著充電）：
  控制列或選單裡二選一：
    ‧「USB 優先」：接著 iPhone 且個人熱點開著時走 USB（預設）。
    ‧「僅 Wi-Fi」：鏡像一律走 Wi-Fi，USB 線只充電。
  選擇會記住。正在投影時切換，目前這次投影會結束，請在 iPhone「螢幕鏡像
  輸出」重新選一次。

  「僅 Wi-Fi」會確實擋下 USB：程式不在 USB 那條網路上回應，手機若仍從 USB
  連進來，連線會被拒絕。因此不需要（也請不要）用「停用裝置／停用網路卡」
  的方式來切換 —— 那會讓 USB 投影失效，在某些接法下還會讓充電中斷。之前
  若停用過「Apple Mobile Device Ethernet」，選「USB 優先」時程式會提示，
  點通知（或「啟用 USB 網路卡…」）並在系統管理員視窗按「是」即可恢復。

關於行動數據：
‧ 投影本身是手機→電腦的本地 USB 傳輸，不經電信、不耗行動數據。
‧ 但個人熱點開著時，Windows 可能讓「電腦自己的上網」改走 iPhone 的行動
  數據（常見於家裡 Wi-Fi 沒有 IPv6、而 iPhone 提供電信 IPv6 的環境）。
‧ 程式偵測到這個情況時會跳通知：點通知（或「省行動數據…」），在系統
  管理員視窗按「是」。只需設定一次。之後這條 USB 線只用來投影，電腦上網
  固定走原本的網路；即使 Wi-Fi 斷線，電腦也不會改用手機流量。
‧ iPhone 的「行動數據」請保持開著：關掉它，個人熱點（含 USB 這條本地
  網路）會一起消失，USB 投影就沒了。
‧ 日後想讓電腦用 USB 線分享手機網路上網，可用系統管理員命令列還原
  （<編號> 是那張 Apple 網路卡的介面編號，用 netsh interface ipv4 show
  interfaces 查）：
    netsh interface ipv4 set interface <編號> ignoredefaultroutes=disabled
    netsh interface ipv6 set interface <編號> routerdiscovery=enabled ignoredefaultroutes=disabled

備註：iOS 16 起 Apple 已停用舊的「QuickTime 有線擷取」協定（不需熱點的
那種），所以本程式不採用；上面的做法是新版 iOS 可行的有線投影方式。


四、視窗、控制列與全螢幕
------------------------
‧ 視窗大小：手機直向時約為螢幕高度的九成；轉成橫向時約為螢幕寬度的一半，
  不會一下子放到占滿螢幕。拖拉視窗邊框可以自由調整，畫面比例會保持不變；
  直向、橫向各自記住你調整後的大小與位置，下次照舊。
‧ 滑鼠在畫面上移動，底部出現控制列；3 秒不動自動隱藏（游標停在控制列上
  時不會隱藏）。
‧ 控制列左邊：目前走 USB 還是 Wi-Fi、畫面解析度。
  控制列右邊：「USB 優先｜僅 Wi-Fi」、靜音（只靜音這個程式，不影響 iPhone
  音量）、更多（⋯，即完整選單）、全螢幕。需要時會多出黃色按鈕：
  「省行動數據」「啟用 USB 網路卡」。
‧ 在畫面上任意處按右鍵，也會打開完整選單。
‧ 全螢幕：雙擊畫面、F、F11 或 Alt+Enter 切換；Esc 離開。全螢幕時滑鼠
  3 秒不動，游標和控制列一起隱藏。
‧ 裁切黑邊：手機螢幕比影片寬（例如 16:9 的影片在 iPhone 上全螢幕播放）
  時，手機會把整個螢幕連同兩側的黑色區域一起鏡像過來。可以把它切掉，
  讓視窗四邊貼齊畫面：
    自動：按 C，或選單「自動裁切黑邊」。程式偵測到四周的黑邊就切掉，
          視窗跟著縮到剛好包住畫面。換到下一部影片時裁切會保持；黑邊裡
          出現別的內容而且沒有馬上消失（例如離開全螢幕播放），大約一秒
          內就恢復完整畫面。為了不被暗場景誤判，只處理兩側對稱、持續約
          1.5 秒以上、而且畫面有在動的黑邊。這個選擇會記住。
    手動：按 X，或選單「框選裁切範圍…」。游標變成十字後，在畫面上拖曳
          框出要保留的範圍，放開就套用；Esc 或按右鍵取消。手動框選只對
          目前這個畫面有效，手機轉向或重新連線後恢復原狀。
    恢復：選單「不裁切」（自動模式下再按一次 C 也可以）。
‧ 最上層顯示：按 T，或選單「最上層顯示」。靜音：按 M。
‧ 投影期間電腦不會自動進入睡眠或關閉螢幕。
‧ 介面文字跟著 Windows 的顯示語言：繁體中文、簡體中文、英文、日文、韓文、
  西班牙文、德文、法文、越南文、泰文；其他語言顯示英文。想固定語言可用
  -ui 選項（見第七節）。


五、畫質／效能模式
------------------
選單裡三選一，會記住：
  ‧「畫質優先」：向手機要求完整解析度，多保留一點緩衝，不跳過畫面。
    適合看影片、簡報、文字。延遲比平衡略高。
  ‧「平衡（自動調整）」：預設。依螢幕、顯示卡與網路狀況自動把延遲壓到
    最低而不卡頓；顯示卡沒有硬體解碼時會自動要求較輕的串流。
  ‧「效能全開」：要求較輕的串流（最多 1920×1080）、緩衝減到最少、來不及
    顯示的畫面直接換成最新的。延遲最低、最省記憶體與顯示卡資源，適合玩
    遊戲或電腦較舊時使用。
延遲與流暢度的部分立即生效；串流解析度由手機在連線時決定，所以解析度的
變更（以及「畫質優先」較深的緩衝）要到「下一次連線」才完全生效（程式會
提示）。


六、記錄檔與當機紀錄
--------------------
‧ %LOCALAPPDATA%\MirrorDock\mirror_dock.log（選單「開啟記錄檔」）。每行
  都有時間；上一次執行的記錄保留為 mirror_dock.previous.log；單一檔案上限
  8 MB。
‧ 每 10 秒記錄一行畫面與聲音統計，沒聲音或畫面不順時可以從這裡看出卡在
  哪一段。
‧ 程式若異常結束，同一個資料夾會留下 mirror_dock_crash.txt（發生位置）與
  mirror_dock_crash.dmp；回報問題時請一併附上。
‧ 從命令列執行 mirror_dock.exe 時，記錄直接顯示在該命令列視窗。


七、進階選項
------------
建立 mirror_dock.exe 的捷徑，在「目標」後面加參數；或在
%USERPROFILE%\.uxplayrc 每行寫一個選項（不加減號），例如：
    n 客廳電腦
    fs

常用選項：
  -n 名稱        iPhone 清單中顯示的名稱
  -nh            名稱後面不加 @電腦名稱
  -fs            一開始就全螢幕
  -mode 模式     quality（畫質優先）、balanced（平衡，預設）、performance
                 （效能全開）；不指定時沿用選單上次的選擇
  -crop auto     自動裁切黑邊（off＝不裁切）；不指定時沿用選單上次的選擇
  -gpu auto      解碼／顯示用的 GPU：auto（預設＝驅動螢幕的那張）、
                 integrated（內顯）、discrete（獨顯）、software（純軟體）
  -h264          只用 H.264（預設：顯示卡能硬體解 HEVC 時讓 iPhone 用 H.265）
  -s 寬x高       自訂要求的串流解析度（指定後不受模式影響）
  -ui en         介面語言：auto（預設）、en、zh-TW、zh-CN、ja、ko、es、de、
                 fr、vi、th
  -vsync 20      讓聲音比畫面晚 20 毫秒（可為負數，用來微調嘴型）
  -vsync no      關閉影音時間戳同步（收到就播）
  -pin           需要輸入 PIN 碼才能連線（PIN 會用通知顯示）
  -nc            iPhone 停止鏡像時保留最後畫面不關視窗
  -ca 檔名       播放音樂時把專輯封面存成檔案
  -d             詳細除錯記錄
其餘 UxPlay 原有選項大多照舊可用（在命令列執行 mirror_dock.exe -h 會列出）。
本程式不含需要 GStreamer 等其他平台元件的功能（HLS 影片投放、MP4 錄影、
畫面上顯示封面、RTP 轉送、畫面翻轉／旋轉、藍牙 LE 廣播等）。舊設定檔裡
若有這些選項，會在記錄檔註明「已忽略」，不影響啟動。


八、參考數據
------------
以下是在一台 2016 年的筆電（Core i7-6700HQ、Intel HD Graphics 530 內顯
驅動螢幕、Windows 11）量到的數字，僅供參考，不同電腦會不同：
‧ 啟動到可連線約 0.5 秒（新下載後第一次啟動會因防毒掃描而較慢）；結束
  約 0.05 秒。
‧ H.265 硬體解碼的鏡像：聲音與畫面之間的延遲平時約 18 毫秒，音畫同步。
‧ 聲音走 WASAPI 低延遲模式，畫面走 DXGI flip-model，影音共用同一條時間軸。


九、建議
--------
‧ 多螢幕「同步顯示」而兩個螢幕更新率不同時（例如 60 Hz 與 50 Hz），
  Windows 只會跟其中一個同步，另一個螢幕上的動態畫面會有輕微頓挫。只看
  其中一個螢幕時，到「設定 → 系統 → 顯示器」改成只在該螢幕顯示即可。
‧ 筆電接上電源時效果最佳。


十、疑難排解
------------
‧ iPhone 清單看不到這台電腦：確認同一個 Wi-Fi、防火牆已允許（見第一節）；
  把 iPhone 的 Wi-Fi 關掉再開一次。
‧ 接了 USB 卻沒走 USB：看選單第二行的 USB 狀態。「請開啟個人熱點」就到
  iPhone 打開個人熱點；「網路卡已停用」就點「啟用 USB 網路卡…」；確認選的
  是「USB 優先」。正在投影時會等這次投影結束才切到 USB，在 iPhone 停止
  鏡像再重新選一次即可。
‧ 選了「僅 Wi-Fi」之後 iPhone 連不上：手機可能還記著 USB 那條路。在 iPhone
  停止鏡像，等幾秒再重新選一次；仍不行時把 iPhone 的 Wi-Fi 關掉再開。
‧ 沒聲音：先看控制列的喇叭圖示是不是靜音，再看記錄檔每 10 秒那行的
  audio 數字（有封包、有峰值、有播出，就是電腦端的音量或混音器被關了）。
‧ 不要用 Zadig 等工具把 iPhone 的驅動換成 libusb：那會取代 Apple 驅動，
  USB 投影會失效。
‧ 聲音與嘴型不同步：用 -vsync 毫秒數微調（正數＝聲音延後）。
‧ 畫面會頓：先試「效能全開」模式；多螢幕同步顯示時見第九節。
‧ 畫面突然全黑後程式自己重新啟動：顯示卡驅動重設或更新了；程式會自動
  重開一次，請在 iPhone 重新選擇。短時間內連續發生時程式會停下來並顯示
  原因，請檢查顯示卡驅動。

十一、從 UxPlay for Windows（1.6 以前）升級
------------------------------------------
‧ 程式改名為 MirrorDock，執行檔是 mirror_dock.exe。請先結束舊的 uxplay.exe
  再啟動新的；舊的執行檔可以刪除。
‧ iPhone「螢幕鏡像輸出」清單上的名稱會從「UxPlay@電腦名稱」變成
  「MirrorDock@電腦名稱」。想沿用舊名稱可加 -n UxPlay。
‧ 原本的設定（USB 優先／僅 Wi-Fi、模式、視窗大小等）第一次啟動時會自動
  帶過來；有設「開機時啟動」的話也會自動改成啟動新的執行檔。
‧ 記錄檔資料夾改為 %LOCALAPPDATA%\MirrorDock（舊資料夾沒有程式在使用時會
  直接改名沿用，裡面的舊記錄檔會留著）。
‧ %USERPROFILE%\.uxplayrc 設定檔與配對金鑰檔的檔名不變，照舊可用。
