UxPlay（本機特化版）使用說明
==============================

針對：iPhone 16 Pro Max（iOS 26）→ Windows 投影，於這台 ASUS 筆電
      （i7-6700HQ / Intel HD 530 / GTX 960M / Windows 11）調校驗證。

★ 換電腦免重設：本程式會自動依「當下這台電腦」的硬體調整 —— 自動選用
  驅動螢幕的那張顯卡（純內顯、獨顯、Intel/AMD/NVIDIA 都可以；顯卡不支援
  硬體解碼時自動改用軟體解碼）、自動抓螢幕解析度與更新率、接上或拔掉外接
  螢幕會即時重新偵測調整、自動用音訊裝置的最低延遲。顯卡若不支援 HEVC 就
  只提供 H.264。程式本身以可攜指令集（x86-64-v2）編譯，任何 Win10/11 x64
  電腦（Intel 或 AMD）都能執行。


一、啟動與結束
--------------
‧ 雙擊 uxplay.exe 即可。不會跳出黑色主控台視窗，右下角系統匣會出現圖示。
  約 0.5 秒內就能在 iPhone 的「螢幕鏡像輸出」清單看到本機。
‧ 第一次執行時 Windows 防火牆會詢問，請勾選「私人網路」並允許，否則
  iPhone 看不到這台電腦。
‧ 結束：在系統匣圖示按右鍵 →「結束」（約 0.05 秒完成，會通知
  iPhone 中斷並把自己從鏡像清單移除）。


二、Wi-Fi 鏡像（建議用法，實測穩定）
------------------------------------
iPhone 與電腦連同一個 Wi-Fi → 控制中心 →「螢幕鏡像輸出」→ 選
「UxPlay@電腦名稱」。畫面視窗會自動出現並跳到最前面。鎖定手機時 iOS 會
暫停畫面但聲音續播，解鎖即自動恢復（正常現象）。

實測（iPhone 16 Pro Max / iOS 26.6，HEVC 由 Intel HD 530 硬體解碼）：
畫面同步延遲穩定在約 15 毫秒，連續數千幀幾乎零掉幀，音畫同步。
這條路不需要安裝任何驅動、不耗任何行動數據。


三、USB 投影（走傳輸線，USB 最優先）
------------------------------------
本版讓投影走 USB 線的方式是「在 USB 網段上跑 AirPlay」。只要那條 USB
網段存在，UxPlay 會自動優先用它（USB 最優先、Wi-Fi 其次），手機畫面
就走傳輸線；拔掉線就自動回到 Wi-Fi。UxPlay 開著時插拔都會在約 2 秒內
自動切換，不用重開（正在投影中則等這次投影結束才切換，不會打斷）。

  1. 安裝 Apple USB 驅動（只需第一次）：執行隨附的
     install_apple_usb_support.cmd（會用 winget 自動安裝 Apple Mobile
     Device Support）。本機已裝好。
  2. iPhone：設定 → 個人熱點 → 打開「允許其他人加入」，接上 USB 線。
     Windows 會多出一張「Apple Mobile Device Ethernet」網路卡（172.20.10.x）。
     iPhone 接上但熱點沒開時，UxPlay 約 8 秒後會跳通知提醒你開熱點。
  3. iPhone 控制中心 →「螢幕鏡像輸出」→ 選 UxPlay。畫面即走 USB 傳輸線
     （本地鏈路，實測 ping <1 毫秒；比 Wi-Fi 更穩更低延遲）。
     視窗標題與系統匣會依實際走的路顯示「USB」或「Wi-Fi」。
  系統匣圖示按右鍵，第二行會顯示 USB 狀態（未連接／請開啟個人熱點／
  已連線 172.20.10.x／網路卡已停用）。

切換 USB／Wi-Fi（線可以一直接著充電）：
  畫面控制列或系統匣右鍵，選其中一個：
    ‧「USB 優先」：接著 iPhone 熱點線時走 USB（預設）。
    ‧「僅 Wi-Fi」：投影只走 Wi-Fi，USB 線只充電、不用來投影。
  切換只改 UxPlay 自己走哪條路，不會動到 USB 裝置，所以不影響充電；選擇會
  記住，下次開啟照舊。正在投影時切換，目前這次投影會結束，請在 iPhone
  「螢幕鏡像輸出」重新選 UxPlay，就會走新選的那條路。
  請不要用「停用網路卡／停用裝置」來切換：停用「Apple Mobile Device
  Ethernet」會讓 USB 投影失效，在你的接法下還會讓充電中斷。若之前停用過，
  選「USB 優先」時 UxPlay 會提示，點通知（或控制列／系統匣「啟用 USB
  網路卡」）並在系統管理員視窗按「是」即可恢復。

關於行動數據（重要，請看）：
‧ 投影畫面是手機→電腦的本地 USB 傳輸，不經電信、不耗行動數據。
‧ 但開著個人熱點時，Windows 可能讓「電腦自己的上網」改走 iPhone 的行動
  數據。實測這台電腦：家裡 Wi-Fi 沒有 IPv6，而 iPhone 會給電腦電信的
  IPv6，所以 Google、YouTube、Microsoft 等支援 IPv6 的連線全都會走手機
  流量（只壓 IPv4 優先度擋不住）。
‧ 本版會自動偵測這個情況，跳出「行動數據保護」通知：點通知（或控制列／
  系統匣的「保護行動數據」），在 Windows 的系統管理員視窗按「是」即可。只需
  設定一次（之後重插、重開機都有效）。設定後這條 USB 線只用來投影，電腦
  上網固定走 Wi-Fi；即使 Wi-Fi 斷線，電腦也不會改用手機流量。
‧ 「行動數據」請保持開著：關掉它 iPhone 的個人熱點（含 USB 這條本地
  鏈路）會一起斷，USB 投影就沒了。投影本身不耗流量。
‧ 若日後想讓電腦用 USB 線分享手機網路上網，可用系統管理員命令列還原
  （<編號> 是那張 Apple 網路卡的介面編號，可用 netsh interface ipv4
  show interfaces 查）：
    netsh interface ipv4 set interface <編號> ignoredefaultroutes=disabled
    netsh interface ipv6 set interface <編號> routerdiscovery=enabled ignoredefaultroutes=disabled

備註：iOS 16 起 Apple 已封鎖舊的「QuickTime 有線擷取」協定（不需熱點的
那種），本版即使完成 USB 信任握手手機也不吐畫面，故不採用；上面的
USB 網段 AirPlay 是 iOS 26 唯一可行的有線投影方式。


四、畫面控制列與全螢幕（跟一般播放器一樣）
------------------------------------------
‧ 滑鼠在畫面上移動，底部就會出現控制列；滑鼠 3 秒不動自動隱藏（游標在
  控制列上時不會隱藏）。視窗模式和全螢幕都一樣。
‧ 控制列左邊：目前走 USB 還是 Wi-Fi、畫面解析度。
‧ 控制列右邊：「USB 優先｜僅 Wi-Fi」切換、靜音（只靜音 UxPlay，不影響
  iPhone 音量）、更多（⋯，同系統匣選單）、全螢幕。
  需要時會多出黃色按鈕：「保護行動數據」「啟用 USB 網路卡」。
‧ 雙擊畫面、按 F、F11 或 Alt+Enter：切換全螢幕；Esc：離開全螢幕
‧ 全螢幕時滑鼠 3 秒不動，游標和控制列一起隱藏
‧ 手機轉向（直/橫）時，視窗會自動依新比例調整大小


五、記錄檔
----------
%LOCALAPPDATA%\UxPlay\uxplay.log（系統匣右鍵「記錄檔」）。
每 10 秒會記錄一行畫面與聲音統計（收到的聲音封包、峰值、實際播出量、
音量），沒聲音時可以從這行看出卡在哪一段。
從命令列執行 uxplay.exe 時，記錄會直接顯示在該命令列視窗。


六、進階選項
------------
可建立 uxplay.exe 的捷徑，在「目標」後面加參數；或在
%USERPROFILE%\.uxplayrc 每行寫一個選項（不加減號），例如：
    n 客廳電腦
    fs

常用選項：
  -n 名稱        iPhone 清單中顯示的名稱
  -nh            名稱後面不加 @電腦名稱
  -fs            一開始就全螢幕
  -gpu auto      解碼/顯示用的 GPU：auto（預設＝驅動螢幕的那張，這台是
                 Intel HD 530）、integrated（內顯，別名 intel）、discrete
                 （獨顯，別名 nvidia；AMD 也適用）、software（純軟體）
  -h264          只用 H.264（預設：顯卡能硬體解 HEVC 時讓 iPhone 用 H.265）
  -vsync 20      讓聲音比畫面晚 20 毫秒（可為負數，用來微調嘴型）
  -vsync no      關閉影音時間戳同步（收到就播）
  -pin           需要輸入 PIN 碼才能連線（PIN 會用系統通知顯示）
  -nc            iPhone 停止鏡像時保留最後畫面不關視窗
  -ca 檔名       播放音樂時把專輯封面存成檔案
  -d             詳細除錯記錄
其餘 UxPlay 原有選項大多照舊可用（uxplay.exe -h 會列出）。
本版不含需要 GStreamer 等其他平台元件的功能（HLS 影片投放、MP4 錄影、
畫面上顯示封面、RTP 轉送、畫面翻轉/旋轉、藍牙 LE 廣播等）。舊設定檔裡
若有這些選項，會在記錄檔註明「已忽略」，不影響啟動。


七、針對這台電腦做的最佳化（實測）
----------------------------------
‧ 解碼與顯示都在 Intel HD 530 上完成：螢幕實體接在 Intel（HDMI），影像
  解碼後零拷貝直接顯示，不經 GTX 再複製回 Intel。
  合成影片基準測試（2868x1320 60fps）：
    Intel  H.264 同步延遲 37 ms、HEVC 28 ms，幾乎不掉幀
    GTX 960M H.264 70 ms、HEVC 122 ms 且掉 70 幀（GTX 960M 沒有完整
    HEVC 硬體解碼）
  真機 Wi-Fi 實測（iPhone 16 Pro Max / iOS 26.6，HEVC）：同步延遲穩定
  約 15 ms。
‧ 不再使用 GStreamer：只有單一 uxplay.exe（不需要任何額外 DLL；
  原本約 250 MB），
  啟動到可連線約 0.5 秒（新下載後第一次啟動會因防毒掃描新檔案而較慢；
  原版 1.2～3.2 秒，另加開主控台約 1.2 秒），
  結束約 0.05 秒（原版約 1 秒）。
‧ 聲音走 WASAPI 低延遲模式（2.7 ms 緩衝），畫面走 DXGI flip-model
  （最多只排 1 幀），影音共用同一條時間軸，依實際網路/解碼狀況自動
  調整到最小但不卡頓的延遲（畫面主導，聲音進來不會把延遲拉高）。
‧ 自動向 iPhone 要求這台螢幕的解析度（3440x1440）與更新率，並允許
  H.265，讓 iPhone 送出接近原生解析度的畫面。


八、建議（系統設定，需你自行決定）
----------------------------------
‧ 目前桌面是「同步顯示」：筆電螢幕 60.02 Hz + 外接 MP341CQ 50 Hz。
  Windows 以筆電螢幕的 60 Hz 合成畫面，外接螢幕每秒會掉 10 幀，動態
  畫面會有輕微頓挫。若只看外接螢幕，請到「設定 > 系統 > 螢幕」改成
  「只在 2 顯示」，畫面節奏會與外接螢幕一致。
‧ 外接螢幕目前走 HDMI（HD 530 的 HDMI 1.4 在 3440x1440 只能 50 Hz）。
  若筆電有 DisplayPort / USB-C 影像輸出，改用它可達 60 Hz。
‧ 使用電源插頭供電時效果最佳。


九、疑難排解
------------
‧ iPhone 清單看不到 UxPlay：確認同一 Wi-Fi、防火牆已允許；重新開啟
  iPhone 的 Wi-Fi 一次。
‧ 接了 USB 卻沒走 USB：看系統匣右鍵第二行的 USB 狀態。顯示「熱點沒開」
  就到 iPhone 打開個人熱點；顯示「網路卡已被停用」就點「重新啟用 Apple
  USB 網路卡」；確認選的是「USB 優先」而不是「僅 Wi-Fi」。正在投影中
  時會等這次投影結束才切到 USB，在 iPhone 停止鏡像再重新選 UxPlay 即可。
‧ 想改回 Wi-Fi：控制列或系統匣選「僅 Wi-Fi」，線照樣接著充電。
‧ 沒聲音：先看控制列的喇叭圖示是不是靜音，再看記錄檔每 10 秒那行的
  audio 數字（有封包、有峰值、有播出，就是電腦端的音量或混音器被關了）。
‧ 不要用 Zadig 等工具把 iPhone 的驅動換成 libusb：那會取代 Apple 驅動，
  USB 投影（熱點網卡）會失效。
‧ 聲音與嘴型不同步：用 -vsync 毫秒數微調（正數＝聲音延後）。
‧ 畫面會頓：多半是上面第八節的「同步顯示 50 Hz」造成，改成單一螢幕
  或讓兩螢幕同更新率即可。
